# ADR：轻量函数计时与双开关

2026-09-28 用户先授权修改方案，随后授权“按照新的方式进行实现”；本决定取代旧重型诊断 ADR。当前为本地实施，未发布。主模块 M13/M15，无业务算法变更。

选择：启动器 --DEBUG 决定构建能力，正式版裁剪；运行时沿用 startPipelineTrace()/stopPipelineTrace()，只读 getPipelineTrace()，不增加可写布尔变量。默认 off，显式开启后记录阶段和覆盖清单内自有业务函数。

理由：复用已有 API/VITE 常量，无新宏框架；start/stop 统一处理未结束调用和迟到回调，避免布尔状态与实际 session 分离。

移出范围：Perfetto、CPU/GPU/内存采样、诊断数据库/传输、跨端时钟与刷新接续、全仓函数插桩。Node/Blender 旧 Trace 移除，远端只记录客户端等待。既有 Performance Lab manual 契约不变，不随 DEBUG 自动启动。

权衡：无远端内部耗时、无跨刷新历史；wall 不是硬件执行时间。正式零新增运行时开销依赖产物检查，DEBUG/off 轻量分支需实测，不能提前宣称零开销。

不新增持久化契约，无业务数据迁移。移除未发布 SQL 不删除已存在的诊断表；历史数据清理另行处理。回退关闭能力或还原诊断代码，不修改业务资产。
