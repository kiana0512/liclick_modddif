## 4. 变更历史：只用于追溯

以下命名模式是日期快照，不应当作当前部署说明：

- `HANDOFF_*`
- `MASTER_UPLOAD_*`
- `MERGE_*`
- `OPTIMIZATION_*`
- `TODAY_*`
- `*_UPDATE_*`
- `performance/LI3D_PERFORMANCE_OPTIMIZATION_PHASE_*`
- 2026 年 7 月的 `RELEASE_AUDIT` 和桌面安装器审计

它们仍有价值：用于理解局部重绘、投影、性能和 UI 为什么演进到当前实现；但其中的本地组件、安装器、ComfyUI 和端口结论可能已经失效。

## 6. 明确过期的桌面方案

任何描述以下内容的旧章节均视为历史：

- Windows 本地组件安装与自启动；
- 4618 loopback 服务；
- 本机莉刻账号绑定；
- “打开本地工作区”作为上传/保存前置条件；
- Cloud 首页安装器下载；
- `/api/comfyui/*` 作为生图服务门禁；
- `nohup node ... &` 作为正式服务器托管方式。

开发遇到冲突时先检查 `codex/modernization` 当前代码和本交接包，再更新当前真源；不要为了迎合旧文档恢复已退役路径。
