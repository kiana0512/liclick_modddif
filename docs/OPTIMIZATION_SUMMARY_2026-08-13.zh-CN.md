# Li3D 优化内容总结

日期：2026-08-13

## 1. 拓扑结果标识优化

- 将拓扑历史中的“模型 1 / 模型 2”改为“低模 / 高模”。
- 第一个输出为低模，第二个输出为高模。
- 降低误选高模进行 UV 拓扑或后续处理的风险。

## 2. 多视图生成模板优化

六视图默认布局调整为：

```text
第一排：正面、左前45°、顶部；
第二排：左侧、右侧、底部。
```

- 删除“右前 45°”视图。
- 新增“底部”视图，补充模型底部结构信息。
- 将“顶部”移动到第一排第三格。

## 3. 局部重绘工作流升级

- 将原有局部重绘逻辑替换为 `Flux2 Klein TrueV3-双图材质编辑-精简测试` 工作流。
- ComfyUI 输入改为：
  1. 当前视角白模图；
  2. 纹理贴图阶段使用的多视图材质参考图。
- 输出仍为一张生成结果图。
- 蒙版不再传入 ComfyUI，只用于限制结果返回后的模型回贴区域。

## 4. 局部重绘操作体验优化

- 用户暂时不需要填写提示词，统一使用服务端固定材质迁移提示词。
- 自动优先使用当前模型最近一次纹理贴图对应的多视图参考图。
- 找不到关联参考图时，回退到当前选中的多视图参考图。
- 缺少有效多视图时提供明确提示，避免提交无效任务。
- 当前视角使用白模捕获，同时保留相机和构图，确保结果与蒙版对齐。

## 5. 局部重绘稳定性优化

- 增加局部重绘服务健康检查和独立配置。
- 区分“服务不可达”和“工作流执行失败”，提供更准确的错误提示。
- 修复主后端与本地组件使用不同工作区时，生成结果无法直接保存的问题。
- 项目写入失败时自动保存到 recovery 目录，避免结果丢失。
- 修复页面刷新后已有结果无法继续应用的问题。
- 修复 GPU 准备失败后再次点击仍然复用失败状态的问题。
- 修复白模/平面模式被误判为 GPU 背景材质未就绪的问题。

## 6. 图像处理性能优化

- 删除旧的蒙版合图逻辑。
- 删除浏览器端 RGBA/Alpha 重编码流程。
- 删除局部重绘输入 Worker 预热和 2K 蒙版输入图生成。
- 改为直接提交白模图和多视图参考图，减少局部生图前的等待和内存占用。

## 7. 烘焙模型对齐优化

- 统一 GLB/GLTF 与 FBX 的米、厘米单位换算。
- 修复不同格式高低模混用时出现的 100 倍尺寸偏差。
- 修复高低模预览叠合不一致的问题。
- 修复跨格式模型的尺寸预检误报。
- 自动 Cage 膨胀改为依据低模自身尺寸计算，避免膨胀距离异常。
- 单位换算只用于烘焙显示和分析，不修改项目保存的原始模型 Transform。

## 8. 优化结果

- 拓扑结果识别更加清晰。
- 多视图结构信息更加完整。
- 局部重绘操作步骤更少，输入关系更明确。
- 生图结果保存、刷新恢复和 GPU 应用流程更加稳定。
- GLB/GLTF 与 FBX 混合烘焙的尺寸和叠合结果更加准确。

## 9. 验证情况

- Server TypeScript 类型检查通过。
- Web TypeScript 类型检查通过。
- Server 与 Web 生产构建通过。
- 烘焙单位测试：5 项通过，0 项失败。
- ComfyUI 双图局部重绘已完成真实任务联调，生成和结果持久化成功。
- 最终蒙版边缘、回贴效果和连续多次重绘由用户继续验收。
