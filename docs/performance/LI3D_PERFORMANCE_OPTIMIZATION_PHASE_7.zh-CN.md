# Li3D 性能优化阶段 7：严格单变量优化记录

更新时间：2026-08-10

## 固定约束

1. 稳定第一，质量第二，速度第三。
2. 产品算法结果与交互语义不改变。
3. 每一步只修改一个可独立回退的性能问题。
4. 每一步执行基线、修改、三轮同场景复测和质量回归。
5. 性能实验室默认关闭；新增诊断必须证明自身不是可见负担。

## 第 1 步：降低性能实验室自身扰动

### 修改前基线

工业切割机器人、4K、`perfLab=1&perfOrbit=1`、持续自动旋转：

- 面板展开：60 FPS，帧 P95 16.8ms，最大 16.9ms，掉帧率 0%。
- 面板收起：60 FPS，帧 P95 16.8ms。

### 修改内容

- 将帧平均值、P95、最大值和掉帧率的多次数组遍历合并为一次统计遍历加一次精确排序。
- 新增只在性能实验室运行的“采集计算 P95 / 最大”自扰动指标。
- 自动旋转轴改为模块级常量，消除每显示帧创建一个 `THREE.Vector3` 的临时分配。
- 新增统计结果精确一致性自动测试。

普通产品路由没有性能实验室组件、性能数据集或采样任务，控制台无错误或警告。

### S6 回归观察

- 页面重载后的第一轮被质量门槛阻断：局部重绘期间背景投影材质重建 1 次。
- 后续热稳态轮完成全部像素、Alpha、背景零重建和持久化检查。
- 连续反馈保持约 15.7–15.9ms。
- 第 2 轮首次 apply 出现 583.8ms 最大帧；第 3 轮为 33.3ms。
- 首笔可见约 141.6–143.1ms；停笔发布最大约 83.4–83.5ms。

结论：第 1 步的调试台改动达到自扰动门槛且不改变产品路径；阶段 7 的下一个单点目标锁定为 S6 冷启动和首次 apply 长帧。不得在解决该问题前叠加新的 GPU/CUDA 算法改造。

## 第 2 步：隔离局部重绘与后台投影升级

### 根因分解

先给 S6 冷首笔增加候选扫描、蒙版读取、射线检测与候选过滤四项计时。最终三轮早点击数据证明冷扫描只有 1.9–2.6ms，蒙版读取 0.8–0.9ms，全部射线检测 6.5–8.9ms，原 550–600ms 长帧不在局部重绘采样算法。

时间戳关联继续确认：14 视图运行时深度/几何法线生成完成后，后台会构建新的纹理数组和投影材质。CPU 分条上传最大仅 1.8–4.5ms，WebGL2 GPU fence 等待约一帧；真正的长帧来自最终材质首次在模型上执行。它与局部重绘覆盖层并无数据依赖，却曾在局部重绘期间竞争同一个渲染器。

同时复现了原始稳定性故障：`localRepaintGpuReadyGeneration` 已发布，但覆盖层已被另一个异步源变更清理，形成“蒙版继续更新、模型没有任何像素变化”。

### 修改内容

- 背景投影修订号只在材质真正提交时递增，不再把取消的异步尝试误报为重建。
- 运行时深度/法线升级在相机手势和局部重绘三种工具模式期间冻结，继续显示上一份完整有效材质；退出工具后再发布同一份最终质量结果。
- 投影数组上传结束后插入 WebGL2 fence，通过 rAF 非阻塞轮询 GPU 队列完成，避免把隐式同步留给下一次材质提交。
- 深度与几何法线 pass 改为每个渲染器复用并预编译两份固定材质；near/far 仍逐次更新 uniform，深度编码和法线公式不变。
- 局部重绘发布 GPU Ready 前再次校验并修复覆盖层：必须仍属于当前模型、挂在模型树、材质未释放且源图/蒙版绑定有效，否则禁止进入应用工具。
- S6 增加冷扫描内部计时与长帧时间关联数据，产品路由仍不启用性能 HUD。

### 全新页面三轮结果

工业切割机器人、4K、14 个投影视图、`perfLab=1&perfOrbit=1`。每轮只等待固定深度/法线 pass 完成便启动 S6；普通投影数组仍处于后台构建，属于比热稳态更严格的早点击条件：

| 轮次 | 交互 P95 / 最大 | 实时反馈 P95 / 最大 | 发布 P95 / 最大 | 按钮 3 就绪 / 首笔可见 | 背景重建 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 18.1 / 53.5ms | 17.3 / 17.4ms | 18.1 / 53.3ms | 26.1 / 151.2ms | 0 |
| 2 | 18.2 / 71.6ms | 17.2 / 17.4ms | 18.1 / 52.8ms | 23.8 / 187.4ms | 0 |
| 3 | 18.1 / 70.8ms | 17.3 / 17.4ms | 18.1 / 70.0ms | 23.7 / 133.9ms | 0 |

三轮都完成 60 个 apply 样本、GPU Alpha 可见性、最终场景像素变化、持久化和背景零重建检查；没有再出现 GPU Ready 与实际覆盖层状态分离。

### 已知剩余项

退出局部重绘工具后，延迟发布的 14 视图深度/法线质量升级仍可能产生一次约 0.5 秒的全局投影首帧。它已从选区、涂抹和停笔会话中隔离，不再造成“边涂边不显示”；下一步将以固定循环投影 shader、最终材质首帧执行和数组资源生命周期为独立 A/B 目标，不能通过降低预览分辨率或关闭法线质量检查规避。
