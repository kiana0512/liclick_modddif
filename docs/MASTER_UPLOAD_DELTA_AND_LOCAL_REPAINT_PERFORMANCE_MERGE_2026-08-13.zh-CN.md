## 1. 本轮结果概览

本轮工作主要包含五条主线：

1. 重整局部重绘三步操作，去除误导状态并增加呼吸引导。
2. 允许不绘制蒙版直接局部生图，同时保持蒙版只控制结果回贴范围。
3. 统一局部重绘生成面板与普通贴图生成面板的视觉结构。
4. 恢复稳定的贴图界面 UV 合并链路，并简化“贴图 → UV → 烘焙”工作流。
5. 合入远端局部重绘 GPU 蒙版累积与画笔性能优化。

## 2. 上次上传 Master 后的局部重绘交互优化

### 2.1 去除误导性的完成对号

- 蒙版画笔不再显示绿色完成对号。
- 局部生图按钮不再显示绿色完成对号。
- 运行中的任务只显示加载状态，不再把“点击过”误导成“步骤已经完成”。

### 2.2 局部生图不再强制要求蒙版

- 局部生图按钮保持可用，不绘制蒙版也可以提交生成。
- 有用户蒙版时，归档并使用用户蒙版限制结果回贴区域。
- 没有用户蒙版时，生成与返回结果按全图范围处理。
- 默认全图蒙版只在本地归档和回贴阶段使用，不会传入 ComfyUI。
- ComfyUI 输入保持为两张图：当前视角白模和多视图材质参考图。

### 2.3 三步按钮引导状态

局部重绘工具栏的最终交互为：

1. 选择蒙版工具后，局部生图按钮开始呼吸引导。
2. 点击局部生图后，引导停止，并持续显示生成中状态，直到结果返回。
3. 结果返回后，局部重绘画笔变亮并开始呼吸引导。
4. 点击局部重绘画笔后，引导停止，同时清理当前临时蒙版绘制记录。
5. 误点回蒙版工具不会让局部重绘结果失效，已生成结果仍可重新进入应用画笔。

### 2.4 生成状态与结果可用性

- 新增明确的局部生图请求中状态，按钮点击后立即进入运行态。
- 生成完成后通过成功序号触发局部重绘画笔引导。
- 局部重绘结果的可用性不再依赖当前临时蒙版 revision。
- 页面上只要存在当前项目、当前模型对应的有效局部重绘结果，就可以继续使用局部重绘画笔。

## 3. 局部重绘生成面板统一

- 局部重绘生成界面恢复顶部三个视图入口：多视图、单视图、重绘效果图。
- 重绘模式显示与普通贴图生成一致的大图预览。
- 恢复参考图选择区域，用户可以看到当前材质参考来源。
- 恢复“纹理提示词”区域的统一外观。
- 局部重绘仍使用服务端固定材质迁移提示词；输入框只读，不会把用户文本传入当前工作流。
- 删除原先单独占位的固定提示词说明卡片，减少两套面板样式并存的问题。
- 点击多视图或单视图可以返回普通贴图预览状态。

## 4. UV 合并与烘焙入口调整

### 4.1 UV 合并恢复到贴图界面

曾尝试在烘焙页面后台执行 UV 合并，但烘焙简化页没有稳定恢复贴图编辑器完整的模型、图层和渲染状态，因此最终撤销该方案。

当前最终流程为：

1. 用户进入烘焙。
2. 系统判断当前对象是否已有可复用的合并 UV 图层。
3. 如果没有，先自动进入贴图界面。
4. 等待模型、视口和图层恢复完成。
5. 在贴图界面自动合并可见投影图层与 UV 图层。
6. 保存完整图层栈并确认合并 UV 已持久化。
7. 携带合并后的 Base Color 自动进入烘焙界面。

这样避免烘焙页的项目图层与运行时图层不同步，也避免合并完成后因页面切换过快而未保存。

### 4.2 外部 UV 模型直接进入烘焙

- 展 UV 页面导入模型后新增“直接传入烘焙”。
- 用户不必先运行自动展 UV 服务，也可以把已有 UV 的外部模型保存为当前项目 UV 阶段产物。
- 进入烘焙时继续携带模型文件和对象关联信息。
- 自动生成的 UV 结果、历史任务结果和外部导入模型现在都能进入下一阶段。

## 5. 工作流界面精简

- 暂时隐藏自动拓扑首页卡片。
- 顶部流程导航由“贴图、拓扑、UV、烘焙”改为“贴图、UV、烘焙”。
- 旧的拓扑链接自动转到展 UV 页面，避免进入已隐藏功能。
- 去掉顶部流程按钮之间的箭头，只保留三个模块按钮。
- 首页模块数量由 5 个调整为 4 个。
- 拓扑源码和历史数据结构仍保留，本轮只隐藏用户入口，方便以后恢复。

## 6. 本次合入的远端局部重绘性能优化

远端提交 `326193a` 只修改了 `ViewportCanvas.tsx`，没有改动 ComfyUI 客户端、服务端路由、工作流节点或服务器地址。

### 6.1 GPU 蒙版累积

- 新增持久化的 GPU 蒙版累积 RenderTarget。
- 多视角蒙版不再主要依赖不断增加的投影快照列表。
- 当前投影可以按添加、擦除和反选状态合入累计蒙版。
- 添加与擦除操作切换时先归档当前投影，避免不同混合语义互相覆盖。
- 空闲时可调度蒙版归档，减少用户下一次落笔时的准备工作。

### 6.2 直接材质显示蒙版

- 对可支持的模型材质注入局部重绘蒙版 Shader。
- 蒙版可直接在模型原材质上混合显示，减少额外 Overlay Mesh 的持续开销。
- 对不适合直接注入的 Mesh 保留累计蒙版 Overlay 作为兼容路径。
- 增加材质绑定恢复和资源释放，退出蒙版状态后可以还原原始材质。

### 6.3 消除抬笔卡顿

- 删除每次 pointer-up 后扫描整个投影画布 Alpha 的同步读回。
- 画笔实时路径已经维护“是否有蒙版内容”的状态，抬笔时直接提交该状态。
- 避免高分辨率画布每画一笔都发生一次完整像素遍历，解决典型的“画一下顿一下”。

### 6.4 GPU 反选与状态保持

- 蒙版反选改为 GPU uniform 状态切换。
- 不再先捕获整张蒙版、在 CPU 逐像素反色、重新写回画布。
- 蒙版存在时保持已编译的材质混合，切换蒙版画笔或局部重绘工具时不再短暂恢复和重新编译基础材质。
- 清空蒙版时同步重置累计 RenderTarget、操作模式和显示状态。

### 6.5 画笔输入与缓存优化

- 增加模型可绘制表面的 WeakMap 缓存，减少重复遍历 Mesh 和统计三角形。
- pointer-up 末点改为参考最后一个已排队采样点，减少重复落点和异常长线段。
- 深度与投影准备改为更适合交互的调度方式，减少落笔前后的同步工作。
- 释放旧快照、深度目标和临时纹理时补全清理逻辑，降低长期编辑的资源累积风险。

### 6.6 性能观测能力

- 新增轻量 FPS、P95 和最大帧时间显示。
- 性能实验室默认折叠，减少诊断面板对视口的干扰。
- 新增局部重绘人工录制，记录落笔/停笔延迟、掉帧、滚轮、长任务和图层操作。
- 自动旋转不再因打开性能实验室而强制启用，手工测试数据更接近真实操作。
