# CHG-20260916-MANUAL-REPAINT-LAYER

## 归属与范围

- 主模块 M08；协作 M03（视口输入/运行时所有权）、M12（图层持久化/历史）；入口 UI-05、UI-06、UI-10。
- 算法 `ALG-LR-MANUAL-TARGET` v1.0.0。修改目标选择和会话交接，不改 `ALG-LR-UV-PAINT` 的像素核。
- 范围为生成面板结果的“步骤 3：应用重绘”画笔；不改独立图片编辑对话框、多视图生成、纯投影选区显示或导航。

## 行为

1. 进入局部重绘、完成远端生成、后台 GPU 预热均不创建图层，也不绑定 generationId 或清理历史结果层。
2. 应用画笔检查当前对象选中的可见 UV 层；无目标、投射层、隐藏层、其他对象层均不可绘制。提示窗提供“新建图层并开始绘制”和“取消”，已有 UV 层可直接选择使用。只有点击创建按钮才创建、记录历史并选中。
3. 新来源保留目标 ID，复制目标现有 RGBA 初始化原生 UV 会话，仅修改笔刷命中像素。名称、角色、图层顺序、透明度、混合及调整参数保留。多选列表仍以单个活动层作为目标。
4. 切层在原 draft/owner 上收尾，等待 dirty-tile 提交后绑定最新选择。无有效目标或目标删除则停止，不选择别的层继续涂，不恢复已删行。
5. 保留旧 projected/native 历史编辑路径；不批量迁移、合并或删除旧层。通用图层删除最后一层时的原有占位层行为未修改，但它不会被本次操作自动继续绘制。

## 全链路审计

- GPU：手动目标使用已有 UV 行 ID 和原生 RGBA owner；先等待历史/读回边界，再复制初始像素；UV 行交接不再等待 projected-mask 材质门禁。
- CPU/history：仍用既有 tile 增量提交、撤销/重做及活动 owner；新 source 不重新解释旧像素。缺失目标在 initialize 阶段同样拒绝发布。
- Worker/shader：无算法/分辨率降级，无新工作线程或着色器变体。
- 初始已有 UV 纹理保持自身分辨率，不因设置变化缩放历史笔画。当前原生绘制核要求方形 UV；非方形已有纹理明确拒绝并提示新建空白层，不偷偷拉伸覆盖。
- 持久化：只更新已有行 imageUrl/contentRevision，复用已验证资产与 Project 保存通道；命令、CAS、ownership、存储预算不变。
- 新 destinationMode 仅存在于运行时 LocalRepaintProjectionSource，不新增 Project/DB Schema。PNG 保存、恢复、导出仍使用完整已提交 RGBA。

## 验证

- 完成：146 项前端回归、前端类型检查、生产构建及包体预算检查；本次改动 lint 无错误（GeneratePanel 保留原有两条未使用变量警告）。
- 新旧两组真实浏览器回归均通过。手动同层用例第一代红色像素 5956 个，第二代增加绿色 788 个，红色数量与原像素不变；屏幕读回为红色 [211,68,34,255] 与绿色 [34,187,68,255]。

- `test:manual-repaint-layer`：选中层只读解析、跨对象/隐藏/投射拒绝、多次来源不改用户属性/图层数、初始化与迟到提交不复活删除层。
- 更新 `test:local-repaint-layer-retention` 中已过时的自动建层预期，保留旧投影显示、擦除和历史交接断言。
- `run-manual-repaint-browser.mjs`：真实 ViewportCanvas、Edge/WebGL、1280×960、1K UV 平面；生产提示窗取消/创建/Escape，两代颜色同层累积且旧像素逐字节不变，GPU 呈现红绿两色，PNG 编码/解码恢复，撤销/重做、A/B 切层、按下中途切层、隐藏及删除目标。
- 浏览器夹具使用本地确定性来源，无付费生图、无远端数据写入。PNG 往返是本地保存格式验证，不声称 A100 端到端保存已测试。

## 迁移、发布与回滚

- 无迁移。旧图层原样保留，可明确选择其 UV 层继续绘制。
- 本次仅本地实现和验证，未推送 master 或部署 A100。
- 回滚本变更即可恢复旧的自动目标策略；新绘制像素已经保存在普通 UV 图层中，旧版本仍可显示/导出，不需还原数据。
