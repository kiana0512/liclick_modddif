# UV 局部重绘白点：可见性栅格判定修复

- 主模块 M08，协作 M03/M05/M07/M11/M12；ALG-LR-UV-PAINT v1.1.1。
- UV_REPAINT_VERSION=3 是运行算法标识，native-v1 ID / 持久 RGBA / Project Schema 不变。
- 用户授权修复，并于 2026-09-11 明确授权推送 master、部署 A100；发布结果以部署后版本/健康检查记录为准。

## 根因与修复

不透明纯色来源也能复现，排除“必须是生成图本身有白点”。1024² UV、256² 视口、32768 个三角形的隔离平面原先漏 33422 / 921600 个内区 texel（3.63%）；起伏曲面漏 312135（33.87%）。这是人工压力模型，不是用户项目的缺口比例。

旧逻辑用 UV fragment 的导数反解屏幕深度平面，再比较最近屏幕像素对应的另一三角形。微小三角形存在退化/数值不稳定，相邻曲面也不是同一平面，严格双向深度相等造成误丢弃。旧梯度第二分量还错误复用了 dy.x，而非 dx.y；新实现删除整段逆矩阵公式，不保留这一条分支。

新 identity pass 在真实屏幕空间保存 float32 面 ID、深度及两个屏幕深度导数，面 ID 使用 flat 插值，避免插值破坏大整数。面一致可直接命中；否则查询覆盖实际投影点的 2×2 深度采样足迹，以半像素坡度范围做保守前后判定。邻点必须与最近前表面的深度平面连续（差异受梯度变化约束），拒绝跨护栏/孔洞的独立深度跳变。空背景不提供放宽深度；仅增加 2e-6 浮点舍入余量，不关闭遮挡、不扩张生成图 alpha、不任意接受邻面 ID。

可见性缓冲长边至少 1024（保持比例，大视口仍用原 drawing-buffer 尺寸），避免缩小窗口后单个屏幕采样跨越太多细分面。输出 UV 仍为用户所选完整分辨率。

## 路径与资源审计

- GPU/shader：只调整当前视角可见性；来源 shader 的相机、深度、作者遮罩、轮廓和 alpha 原样保留。共享 UV 仍由最强有效笔刷命中取色，同权重稳定排序；独立 composite 仍只擦除一次。
- 显存：RGBA8 ID + 采样 depth 改为 RGBA32F + 深度 renderbuffer。按深度约 4 bytes/像素估算，可见性缓存从约 8 增为 20 bytes/像素；1024² 约 20 MiB，3840×2160 约 158 MiB。面属性从每顶点三个 float 减为一个（每三角形节省 24 bytes，32 万面约 7.3 MiB）。缓存只有一份，随视角/尺寸失效重渲染，会话释放；没有每 stamp 新建目标。设备缺少 EXT_color_buffer_float 时明确拒绝准备，不写图层、不静默退回错误路径或降低纹理尺寸。
- CPU：矩阵/瓦片裁剪、异步脏瓦片读回、before/after 历史、选区 alpha 增量消费不变。CPU 不另行“补点”。
- Worker：接收同一 committed RGBA，没有独立可见性算法要同步，原 PNG/读回转换继续使用。
- 保存/合并/PNG/FBX：继续等待 live commit barrier，消费同一原生 UV RGBA；无重投影、无自动补洞。Command 幂等、CAS、ownership、verified assets 不变。
- 单视图、旧 projected 重绘、返图请求与资产均不改。

## 验证

- 新真实 Edge WebGL 逐像素夹具：平面/起伏曲面 × 正交/透视 × 256/1024 视口，8 组每组 921600 个内区像素，均零漏点；额外倾斜双层相距 0.01 的后表面不被绘制。
- 额外 4K 起伏曲面、旋转相机、512×256 非方形小视口：14745600 个内区像素零漏点，不只验证 1K 或正对平面。
- 原浏览器回归：护栏遮挡、孔洞后板、大笔刷、转角、共享 UV/镜像/部分重叠、同权重取色、撤销重做、擦除、source alpha/作者遮罩、生产来源 shader 通过。
- 实际 React 视口：5956 覆盖像素；擦除/撤销/PNG/重开通过，FBX 颜色 [211,68,34,255] 与 UV 一致，PNG 为 1024²。
- 32 万面、4K 输出压力模型：准备约 134.5ms（含构造 57.3ms），stamp CPU 提交中位 0.8ms / 最大 5.3ms。仅合成模型命令提交时间，不是端到端 FPS 或真实项目性能承诺。
- 116 项 Web 回归通过；全仓 typecheck 通过；lint 0 errors / 14 项既有 warnings。Cloud 配置 Web 构建及原包体门禁通过（88 chunks，3220768 bytes，未放宽预算）。

## 限制、迁移、回滚

发布准备：完整 Cloud/performance-lab/版本元数据构建原测 3221268 bytes，超出原包体门禁 268 bytes；只移除本模块两个 GLSL 字符串中 327 bytes 冗余空白（去空白后 token 文本完全相同），不调整预算/画质/算法。随后再次运行全部真实 WebGL/React 夹具通过，最终产物门禁以发布记录为准。

可见性仍是有限分辨率栅格算法，不承诺区分亚像素遮挡或深度精度内的几乎共面薄片。邻域连续性约束不能等价于精确几何射线证明；护栏实测夹具通过不等于用户原模型完成验收。当前只有截图，尚未用用户原工程重放这笔绘制，也没有 A100 在线试用验收。

不重写已有资产/UV/历史。旧 PNG 中已经存在的空点不会被自动扫描修补，需要在新算法下用原返图重新涂抹该处（不保证修复来源图本身的白色像素）。回滚到 984fb1d 或上一发布：已有 RGBA 正常可读，只恢复原新笔画算法与原缓存配置，不删除用户内容。
