## 上传优化 AUTODL-DIRECT-REPAINT-UPLOAD/1.0.0

用户授权实施 gzip 请求压缩与重复多视图参考缓存，主模块 M08，协作 M15。浏览器对原 JSON 字节使用原生 CompressionStream gzip；压缩后更大或无压缩能力时保留原请求。没有图像重编码、降分辨率、颜色/法线/蒙版/alpha 改动。GPU/CPU/Worker/shader、回贴、持久化 Command/CAS 和导出算法不改。

云端 aiohttp 接受 Content-Encoding: gzip，CORS 仅补充该请求头，仍须独立访问码，解压后仍执行原 160MiB 请求上限和四图解码校验。首次成功受理后返回 materialCacheId：参考 dataUrl 的 SHA-256。服务器仅允许 64 位十六进制引用，在受保护 references 目录中原子落盘，读取时校验摘要。浏览器仅在当前页记住上一张相同内容的参考图 ID，换参考图自动完整上传，刷新后首次仍完整上传，不将访问码或缓存内容写入工程。
