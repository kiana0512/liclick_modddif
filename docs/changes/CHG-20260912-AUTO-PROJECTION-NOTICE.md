# CHG-20260912-AUTO-PROJECTION-NOTICE

## 范围

- 主界面：UI-05/UI-06。
- 模块：M03/M04。
- 行为版本：`GENERATION-AUTO-PROJECTION-NOTICE` v1.1.0。

## 问题

已完成图片缺少对应历史相机捕获时，自动投影恢复每五秒重试一次。Toast 的可见时间为七秒，因此同一告警会被周期性保持或在关闭后再次弹出，干扰 UV 和贴图操作。

## 修改

- 自动投影恢复完全静默运行，不再显示“图片已生成，正在重试自动投影” Toast。
- 后台五秒恢复轮询、错误去重与成功后清理不停止；首次原因变更仅写入诊断日志。
- 不把缺失相机捕获错误降级为错误方向投影，也不跳过严格回贴屏障。

## 验证与回滚

- 回归覆盖连续两次相同失败均不产生 Toast，第三次恢复成功并创建图层。
- 无 Schema、资产、投影像素、UV、分辨率、QA、持久化或导出变更。
- 回滚可恢复 catch 分支的 warning Toast；无需数据迁移。
