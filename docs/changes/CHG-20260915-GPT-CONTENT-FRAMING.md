# GPT 模型轮廓裁切与精确比例

- 日期：2026-09-15；算法：`GPT-CONTENT-FRAMING/1.0.0`；状态：本地候选，未推送/部署。
- 主模块：M03 捕获、M04 生成；协作 M08 局部重绘、M12 服务端、UI-05 任务恢复。
- 问题：固定方图留下大量空白，模型没有充分使用远端生成画面。

## 输入、输出和坐标

1. 单/多视图贴图读取捕获的完整几何轮廓；GPT 局部重绘读取同相机几何法线的 Alpha，不使用作者局部选区计算外接框。轮廓捕获忽略可配置的视口背景，保留其他对象隐藏和捕获后恢复机制。
2. 逐像素轮廓外接框四周增加最长边 3% 的边距，每侧至少 2px；宽高比超过 3:1 时只扩展短边，不切掉模型。可越出原画布，此处补透明背景。依据的是可见模型，不会补出原镜头外不可见的部件。
3. 结合图和法线使用同一个整数平移裁切，不缩小原始引导图；可选材质参考原样保留。现有精确上传预算、取消及付费前保存门禁不变。这里是裁切已有截图，不是重新渲染增加输入细节。
4. 对裁切宽高求最大公约数，服务端发送 `extra_params.aspect_ratio_w/h`，例如 1710×1470 → 57:49。按已核对的服务约定，自定义比例覆盖 `aspect_ratio` 预设。三种 GPT 模型均支持，保留当前质量、透明背景及用户既有 4K→2K 生图映射。
5. 回图用 framing 中保存的位置还原到原捕获坐标的透明画布，再交给既有投影/局部重绘流程。为保留远端细节，原坐标画布可随回图等比增大，不把回图强制缩成原截图大小。局部写入仍由原作者蒙版控制。
6. 允许像素取整导致的小比例差，明显比例不符直接报错，禁止把方图强拉成目标比例。回贴画布边长不超过 16,384、面积不超过 64 Mi 像素，超限提示放大模型后重试，不自动降分辨率。此上限是在收到图片后检查，极小占屏模型仍可能在付费生成后被阻断；正常取景不应依赖此保护作自适应取景。

## 持久化、旧任务和回滚

- `GenerationFraming` v1：`sourceWidth/sourceHeight/left/top/width/height`，单位为原捕获像素，左上原点；服务器验证整数、相交范围和比例。
- 作为生成任务 input 的可选字段保存，不修改 Capture 相机、尺寸、mask/depth。提交、轮询和历史查询返回 framing；`Generation.metadata.generationFraming/framingRestored` 记录客户端还原。
- 即时结果与轮询结果在 API 适配层还原。历史列表不批量解码图片，只在缺少已保存工程结果的恢复路径还原。已还原结果幂等跳过。
- 服务端原任务日志清洗和重启加载保留数字字段。旧任务缺字段完全走旧路径，无批量迁移，不改写既有资产。
- 前后端需一起发布/回滚：旧前端无法解释新裁切结果。回滚应等待/取消新版本在途任务，保留已还原的工程资产，不能把尚未还原的远端裁切图当作旧式完整视图回贴。
- 无 Project Command、Revision CAS、ownership、verified asset 协议变更。

## 对应算法审计

- GPU、CPU、Worker、shader、UV 和导出没有增加各自的裁切变体：进入这些路径前已统一恢复原归一化坐标。
- 原深度及作者 mask 与归一化坐标保持对齐；保留 GPT 回图 Alpha 策略，不扩大作者选区。
- 普通参考生图、六视图参考生成/第二阶段去光和原 ModelView 重绘均不启用本规则；多视图贴图的每个视角独立算框。
- 图像操作位于独立懒加载模块，不在 React 面板或 Store 实现算法。

## 验证与门禁

- 数学回归：横/竖图、靠边对象、最小对象、3:1 扩边、57:49、取整容差、错误回图比例、安全范围、逆映射归一化坐标误差小于 1e-10。
- API 回归：实际序列化、即时/轮询结果、历史按需恢复、幂等、取消，三种模型、两个 workflow 的自定义比例；执行生产日志清洗/重启函数验证 framing 留存。
- 浏览器夹具：`apps/web/scripts/fixtures/content-framing.html`，真实 Canvas PNG 裁切/回贴、2K RGBA 靠边逐字节回环、同框法线、材质参考不变、放大回图保持细节和位置、真实 WebGL 白背景轮廓/法线捕获。
- 本地验证通过：Web 125 项、Server 19 项回归；新增生产任务清洗/重启测试；typecheck、lint（仅 2 条原有未使用变量警告）、全工作区构建、`verify:modernization` 边界/合同检查和包体门禁。浏览器夹具 10 类检查全部通过。尚未执行针对正式提交的 `verify:prepush`；未调用付费生图，未验收远端模型是否改变构图；几何反投影的正确性不保证模型自身生成内容逐像素锁定。
