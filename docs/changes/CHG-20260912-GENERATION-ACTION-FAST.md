# 生成参数下移与多视图固定加速

- 主模块 UI-05 / M04，协作 M08；算法 GPT-MULTIVIEW-PAIR-SEQUENCE v1.4.0。
- 用户授权：参数移至生成按钮上方，原局部重绘不显示；多视图仅保留最多四张并发；验证后推送 master、部署 A100。
- Sunburst/Flare、五档质量及关联提示统一放在底部按钮区，选择和任务锁不变。ResizeObserver 同步侧栏避让高度，卸载释放观察器并还原 CSS 变量，原局部重绘自动恢复单行按钮高度。
- 删除 stable 调度分支和交互切换。首组两张，后续最多四张；10 视图 2+4+4，14 视图 2+4+4+4。只合并相邻完整配对，不推测自定义相机角度。
- 同组先冻结全部输入，再并发请求；按固定顺序回贴，等待真实材质呈现后准备下一组。失败保留成功结果，停止后续组；取消沿用任务身份门禁。
- 历史 textureMultiviewMode 字段可读取、保留，但不再参与调度。无需批量迁移，不回写旧任务、图层或资产。回滚本次提交可恢复旧布局和模式选择；已有生成结果继续可用。
- GPU/CPU/Worker/shader、投影质量与裁切、UV 合并、导出、Alpha、分辨率、Project Command、Revision CAS、ownership 与 verified assets 均不变。未完成的 GPU 橡皮原型明确排除本次发布。
- 验证：真实 JSX/控件及高度观察器的浏览器夹具覆盖 24 种布局（单/多/GPT 重绘/原重绘、292/312px 宽、720/900/1080px 高），检查无遮挡、模型/质量写入、锁定、取消及卸载清理；调度回归覆盖默认/旧 stable/fast/未知设置、10/14 视图、自定义相机、乱序返图、失败和取消。未进行付费真实生图，不承诺固定耗时收益。
