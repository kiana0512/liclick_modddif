# 新手引导简化

## v3.0.1 入口位置调整

新手引导固定放在顶部工具栏分辨率（2K）右侧，展开步骤卡时入口仍可见；窄屏允许工具栏换行。移除“定位操作区”按钮，进入步骤自动展开目标面板并滚动到对应控件，继续保留操作区高亮、步骤卡、收起、暂停与继续。操作区仍不存在时提示展开左侧面板或先导入并选中模型，不引导点击已删除按钮。

范围为 UI-01，三个生产文件；沿用 v3 本地进度，无 Schema 或数据迁移，不更改生成、绘制、GPU/CPU/Worker/shader、保存和导出。回滚此次三个文件即可恢复原入口和定位按钮。本轮仅本地修改，未推送/部署。验证使用真实 EditorShell + 教程组件浏览器回归及 Web typecheck、修改文件 lint。

- 主模块：UI-01 编辑器入口，协作 UI-05 生成面板、UI-10 绘制工具栏。
- UI 状态规则：TEXTURE-ONBOARDING v3.0.0；本地实现与检查已完成，尚未推送/部署。
- 范围：仅新手教程。五个生产源文件，引导独立 lazy chunk 加载，保持原有编辑页包体上限；不修改导入、生成、投影或绘制业务流程。

## 用户行为

基础教程为「导入模型 → 添加参考图 → 生成纹理」。单视图调整、局部重绘从「新手引导」菜单主动选学，不再要求清空图层。每步只解释当前操作，提供定位和收起；卡片按实际高度避让目标，无法容纳时收为入口。目标不存在或不可见时不假装高亮，提示定位操作区。

关闭与 Escape 保存暂停状态；继续恢复当前步骤，重新学习从第一步手动复习。生成任务期间只隐藏教程，保留实例，项目切换通过 key 隔离。显式新建入口仅在没有进度时启动，不覆盖已暂停或完成记录。返回上一步不被已有条件立即推回去。

基础第三步的完成条件是生成成功、有结果、回贴 commit、对应可见且非零透明度图层存在，并且生成/面板操作已解锁。该条件不宣称验证 GPU 最终像素或图像质量。可选单视图需要一次新的生成结果；局部蒙版需要实际内容，生图需要新的可用结果，最终涂抹需要用户点击「已涂抹并确认效果」，不会通过选择画笔自动完成，也不会为教学额外发起付费任务。

## 持久化、迁移与回滚

仅使用 li3d:texture-onboarding:v3:<projectId>，包含教程、步骤、active/paused/done、复习标记与已有生成 ID。无图片数据或凭据；存储拒绝/配额失败时使用会话内回退。v1/v2 已完成或已进入进阶步骤的项目映射为基础完成；旧基础进度迁为暂停并保留步骤，避免主动打扰。旧键不删除，回滚恢复组件及其 v2 读取即可；不触及 Project Command、Revision CAS、ownership 或 verified assets。

## 对应实现审计

CPU/GPU/Worker/shader、像素/颜色空间、UV、原分辨率、保存、导出均无修改。DOM data 属性仅提供现有业务状态，生成面板图层订阅只返回布尔值，避免每笔图层更新触发新教程订阅重渲染。卡片每 350ms 检查可见目标，条件稳定至少 500ms 才自动前进；暂停/隐藏/卸载清理监听与计时器。
