# ModelView 多视图按需快照

- 日期：2026-09-21；主模块 M04，协作 M03/M05/M06/M09；ALG-GEN-006 v1.1.0 → v1.2.0。
- 用户授权：首个视角准备好即生成，之后轮到哪个视角再准备该视角。

## 行为与决定

旧流程在首次请求前捕获并保存整批 10/14 个视角。本次仅改变 ModelView 的串行准备时机：切换视角 → 冻结当前贴图/相机/对象矩阵 → 捕获本视角 → 合成白模或补全输入 → 保存完整 Capture → 提交生成 → 回贴驻留 → 下一视角。

当前贴图必须在临时白模材质发布前冻结，防止后续视角丢失上一张已生成纹理。当前贴图、白模、法线、mask/depth 共用该视角冻结相机；对象矩阵改为每个视角同步记录。当前视角按全量相同分辨率生成，不复用低分辨率缩略图。下一视角不提前捕获或并发提交。

每次保存读取项目最新 captures，保留其他编辑新增快照；完整 capture 保存成功后才允许提交对应远端请求。全部覆盖仍跳过、不提交；取消、捕获或保存失败均阻止后续视角，保留已完成结果并恢复原相机。每张进度映射到整批区间，共用快照函数在此入口关闭默认的全量快照进度，保留准备阶段编辑锁。

## 对等审计与回滚

- GPU/CPU/Worker/shader：仍调用原 capture、补全、投影及 resident barrier；未改像素计算或蒙版。GPU 捕获仍串行。
- GPT 成组与单视图：共用快照函数默认行为不变，仍使用已有捕获和进度规则。
- 持久化/导出：沿用 Capture 资产、相机/矩阵、Command 幂等、Revision CAS、ownership 和 verified assets。回贴/export 使用同样完整数据，未改 Schema，无数据迁移。
- 回滚只恢复 ModelView 整批预捕获；保留已保存资产、生成记录与图层。没有后台断点续跑协议变更。
