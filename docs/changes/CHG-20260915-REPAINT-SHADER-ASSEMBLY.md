## 修复与审计

GPU：恢复原冻结源图投影调用，颜色、alpha、权重、可见性、深度、羽化、擦除与分块公式不改。CPU：输入、包围盒、脏块回读和历史不改。Worker：仍消费相同 RGBA；没有新副本/降采样。shader：其他源图/片元/选择消费入口已使用空白兼容正则，mask-only UV 替换仍匹配未改变的表达式。持久化及导出：版本、资产、Command idempotency、Revision CAS、ownership、PNG/FBX/合成输入保持，不改写已存历史；此前没有落下的笔画需要重新绘制。
