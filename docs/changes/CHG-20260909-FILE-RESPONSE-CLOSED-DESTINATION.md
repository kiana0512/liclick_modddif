# 文件响应中断导致服务退出

- 主模块：M14；契约：FILE-RESPONSE-LIFETIME v1.0.1。
- 证据：4517 后端日志依次出现 ERR_STREAM_UNABLE_TO_PIPE、ERR_HTTP_HEADERS_SENT，随后 Node 进程退出。
- 修复：已关闭/已结束响应不再启动文件流；pipeline 同步失败释放源流；请求异常处理在发送头之后终止连接，不追加 JSON。
- 验证：实际 HTTP 测试覆盖下载取消、完整文件字节、读取失败、提前关闭/结束、部分响应失败与正常 500；异常后同一服务器仍能完成请求。服务端构建和修改文件 ESLint 通过。4517 重启后健康检查成功，实际打开“割草机器人”模型可显示。
- 范围：项目当前保存 22 层；尚未复现用户报告的约 30 层后消失，不能将该渲染问题视为已修复。
- 兼容：不改 GPU/CPU/Worker/shader、投影/UV/导出、分辨率、认证、ownership、路径校验、Command 幂等性、Revision CAS 或 verified assets。
- 迁移：无。回退三个服务端源文件并重建即可，但会恢复断连崩溃风险；不修改用户数据。
- 发布：仅本地修复验证，未推送或部署 release。
