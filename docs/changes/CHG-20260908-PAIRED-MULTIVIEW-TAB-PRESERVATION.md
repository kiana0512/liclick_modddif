# CHG-20260908-PAIRED-MULTIVIEW-TAB-PRESERVATION

- 日期：2026-09-08
- 主模块：`M04` 生成编排
- 界面：`UI-05`

## 问题与目标

单视图纹理生成只有单图参考时，会先在后台生成并保存配对多视图参考。旧逻辑在保存完成时同时把生成页签、纹理预览模式和视图模式切到多视图，导致用户在任务进行中被带离原先操作的单视图页签。

## 修改

- 配对多视图结果仍写入参考图分组，并保持为后续纹理生成使用的当前材质参考。
- 保存配对结果不再写入 `tab`、`texturePreviewMode` 或 `textureViewMode`。
- 页签切换只响应用户显式操作；从单视图发起的任务完成后继续显示单视图。

## 边界、验证与回滚

- 不修改生成图片、提示词、参考图资产、任务轮询、投影、分辨率、Project/Generation Schema、Revision、ownership 或服务端接口，无数据迁移。
- 回归检查保证配对多视图仍被选中供管线消费，同时禁止持久化流程触发多视图导航；另执行 Web typecheck、发布构建及 Cloud 产物门禁。
- 回滚只需恢复配对参考保存后的三个界面状态写入，不删除任何参考图或工程资产。
