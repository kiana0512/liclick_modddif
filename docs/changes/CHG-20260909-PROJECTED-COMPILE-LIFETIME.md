# 多层投影异步编译期间保留材质

主模块 M06，ALG-PROJ-007 v2.1.6。浏览器日志出现 Three.js compileAsync 轮询中 isReady 读取 undefined；用户报告多投影层后模型暂时消失。当前可访问页面随后已显示模型，尚未证实此异常是该截图的唯一原因。

投影编译 helper 对参与编译的材质计数；生成材质释放及程序缓存淘汰在计数清零后执行。SceneRoot 的同步等待编译入口使用同一 helper；framebuffer 仍在同步调用后立即恢复，不跨 await 占用。多次编译全部完成才释放，失败也释放引用。普通渲染、材质像素、GPU/CPU/Worker/shader、UV/导出、分辨率与持久数据不变。

验证：两次未完成编译共享材质，中途释放请求不执行，最后一次完成后执行一次；原 framebuffer 同步/异步错误恢复测试与投影显隐测试通过。用户项目仍需复现确认，不能宣称所有层数异常已解决。

无 Schema/资产/ownership/CAS 迁移。回退 helper、释放入口和 SceneRoot 接入即可，可能重新出现轮询访问已释放材质。未推送此修复。
