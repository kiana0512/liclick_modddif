# CHG-20260903 局部重绘切换橡皮擦无闪烁交接

## 问题

新局部重绘图层刚发布后，画面仍由已经预热的精确 GPU 叠加层呈现。用户立即切换橡皮擦时，旧逻辑会按工具状态提前隐藏该叠加层，但共享投影材质尚未完成新图层与实时蒙版的绑定，导致重绘结果暂时消失，并在材质准备完成后才恢复。

## 修改

- 切换到当前局部重绘图层的橡皮擦时，继续保留已可见的精确 GPU 叠加层。
- 在持久投影材质尚未就绪时，允许该精确叠加层继续承担显示和擦除反馈。
- SceneRoot 在交接期间保持持久图层静音，避免新旧显示所有者重叠。
- 确认持久蒙版已经绑定后，沿用两帧原子交接，再撤下精确叠加层。

## 不变项

- 不改变局部重绘生成、蒙版内容、图层顺序和持久化格式。
- 不改变普通 UV 图层及普通投影图层的橡皮擦逻辑。
- 不降低纹理分辨率，不跳过最终持久材质绑定。
