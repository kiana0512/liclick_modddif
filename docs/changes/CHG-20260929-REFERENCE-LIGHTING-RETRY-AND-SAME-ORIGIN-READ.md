# 生产参考图旧失败任务恢复与同源读取

- 日期：2026-09-29；状态：待正式门禁和生产复验。
- UI/use case：UI-05 多视图参考图后台去光照、生成按钮；M04 主模块，M14 资产读取协作；`REFERENCE-LIGHTING/2.0.2`、`ASSET-READ-FALLBACK/1.1.0`，Patch。
- 输入：用户、工程、参考图 ID 与原图内容 SHA-256、已保存的参考图任务状态和 `taskId`；同源 verified 项目资产 URL。输出：复用既有成功/运行任务，或为明确未提交的失败任务递增尝试 ID；浏览器通过同源 `content?proxy=1` 获得原始字节。
- 现象和根因：生产部署后账号菜单仍显示个人莉刻账号已绑定，但旧 `reference-lighting-...` 任务已经以先前版本的“共享凭证”错误持久化为 `failed`。HTTP 200 仅表示查询成功，客户端会重复读取同一失败任务并在控制台抛出旧错误。另一个独立现象是浏览器先尝试对象存储签名 GET，CORS 失败虽能进入代理回退，却每次产生控制台错误和额外等待。
- 规则：只对 `failed`、无远端 `taskId` 且错误属于已知凭证/明确未上传类别的任务产生下一尝试 ID；保留旧任务历史。同一内容及用户的并发消费者复用新任务。已接受付费任务、含糊网络失败和成功绑定不自动重交。项目资产的 Blob 读取直接走现有同源代理；代理继续验证 Session、user/project/asset ownership、verified 和上游长度/MIME/编码，保留签名 GET API 供其他用途。
- 单位/颜色空间/矩阵空间/常量：SHA-256 仍为字节摘要，任务身份输入不变；无像素、颜色或矩阵计算；重试错误集合为明确文案，不改变图像分辨率或 QA。
- 六路径审计：GPU 不适用（任务身份和网络传输）；CPU 图像算法不变；Worker 不适用（浏览器主线程任务编排）；shader 不适用；persistence 保留旧 Generation 记录，只在本地尝试计数生成新 ID，未修改 Project Command、Revision CAS、数据库 Schema 或资产内容；export 不适用（无输出图像格式/方向变化）。局部重绘消费同一参考图读取函数，但投影、UV 和合成像素不变。
- 验证：`test-reference-lighting` 覆盖旧共享/个人凭证错误只新交一次、并发去重、成功重载稳定、带 `taskId` 和含糊网络失败不重交；`test-cloud-base-path-assets` 覆盖同源代理为唯一 Blob 读取请求；正式发布运行 `verify:prepush` 和 CI/CD。实际付费生图仅能由已登录生产用户复验，不能用 HTTP 200 或模拟任务代替。
- 迁移/回滚：无需改写旧项目、任务或对象；新客户端在读取旧明确失败任务时惰性创建新尝试。可回滚客户端到上一版，服务端代理和历史资产不删除；回滚后旧错误会再次重放，签名 GET 的 CORS 噪声恢复。
