# 视角对齐的笔刷范围

主模块 M08，UI-06/UI-10，协作 M06/M07；交互算法 `VIEW-ALIGNED-BRUSH` v1.0.0。

用户录屏要求：笔刷圆环始终朝向视角，经过斜面与硬边时不再跟随表面法线倾斜成椭圆。

## 修改

- 当前相机的世界矩阵右/上轴决定屏幕笔刷投影，圆环与屏幕蒙版共用相同范围。普通画笔、橡皮、选区和局部回贴使用同一入口。
- GPU 原生 UV 回贴和投影橡皮继续消费屏幕圆形半径，不再因命中斜面而取到压扁的短轴。
- 普通 UV 画笔及旧版回贴 fallback 将视角轴沿当前观察射线映射到命中平面，得到对应的局部 UV/源图微分；避免圆环变圆而旧落笔仍是表面切平面圆。
- 透视相机采用命中点至相机的观察方向，正交相机采用平行方向；相机带父变换时使用世界矩阵。近乎相切/退化几何继续使用既有有限圆形回退，旧源图范围上限保留。

## 审计与验证

GPU/Shader：输入半径随新朝向计算，原投射、可见性、深度遮挡、羽化与 Alpha 算法不变。CPU：旧 UV 和源图范围同步修改，既有局部仿射近似与安全边界保留，不宣称极端掠射下与非线性 GPU 投影逐像素等同。Worker、完整分辨率、QA、正式导出与历史/持久化协议不变。

实际生产函数验证 32 组组合：透视/正交、宽/高画幅、父相机旋转平移、非均匀缩放、0/30/60/80 度表面、偏离中心命中，以及 UV/源图范围对应。相切输入不得除零。

真实 Edge DPR=2 视口验证 0/60/80 度模型表面的 SVG 圆环轴长一致且不倾斜。既有 GPU 检查通过：平面/曲面、透视/正交、遮挡、旋转、擦除、撤销重做；含 4K 曲面透视用例。原生回贴经真实 pointer 点击、擦除、撤销、PNG/FBX、重新打开及多图层显隐检查通过。所有既有验收断言保留。

## 迁移、回滚与边界

无 Schema 或数据迁移；仅后续交互使用新朝向，已保存笔迹和资产不重写。回滚恢复 ViewportCanvas 三个范围构造函数的表面切线方案并移除 helper。大小、压感、羽化、目标选择和背面遮挡规则保持原逻辑；本修改不增加穿透绘制。

用户已授权推送 master 并部署 A100。发布集成保留 master 的 UV-only 显示与 detached 上传优化；版本与部署验证结果单独写入发布记录。
