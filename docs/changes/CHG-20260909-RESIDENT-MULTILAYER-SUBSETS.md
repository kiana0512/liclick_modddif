# 多层投影驻留子集复用

- 主模块 M06，ALG-PROJ-007 v2.1.11；实现 Patch，不改混合公式。
- 保留已编译材质的原始槽位。当前输入是原输入的有序子集且至少两层时，把未参与槽位的不透明度置零；结构签名必须继续匹配来源、相机、对象矩阵、遮罩、深度、法线及采样器配置。校验在写入任何 uniform 前完成，顺序变化、新来源和不兼容配置仍交给原工厂重建。
- 橡皮擦保留原始槽位索引，目标不在当前子集时禁用；输入图层不修改。只保留现有材质输入引用，不预载隐藏资源、不增加材质缓存容量。
- **单层不复用多层 shader**：真实 WebGL 对照发现现有单层覆盖公式与多层 Top-K 输出不同，早期允许单层复用的实验已撤回。空层继续走白模，单层继续走原单层路径；不能把早期 S7 的 480→0 重建、90→6 状态错误当作最终收益。
- 回归：570 次多层子集切换，橡皮目标索引、空/单层/重排/来源/相机/采样器拒绝、拒绝时无部分 uniform 写入、原输入和 shader/version 不变。实际 Edge WebGL 的 direct / texture-array、PBR / normal / wire、3→2/3 子集共 24 组，393,216 字节对照零差异。测试不是全部模型/设备的美术验收。
- 复用现有 samplerFeatures 构造 shader 和签名，去除等价重复表达式以遵守原包体预算；不放宽门禁。
- GPU 仅改已有 uniform，CPU 仅做兼容判定；Worker、shader 公式、QA、4K、持久化和 export 不变。Project Command 幂等性、Revision CAS、ownership、verified assets 不变，无 Schema 或资产迁移。
- 回滚移除此子集分支和输入快照字段即可，恢复原重建行为；保留已生成资产。单层快速连切和冷资源加载仍需后续修复，不宣称零卡顿。
