# 红条纹选区显示强度修正

- 主模块：M08；入口 UI-06/UI-10，协作 M03。
- 算法：INPAINT-SELECTION-DISPLAY/1.0.0（新增显示专用变换）。
- 基线：7fc7805f；仅处理用户确认远端输入正常、视口显示 UV 淡缝的问题。

## 变更与边界

原显示 alpha 为条纹/底色透明度乘连续蒙版覆盖值，线性采样造成 UV 岛边缘覆盖偏低时淡缝明显。新增 engine GLSL helper 将显示覆盖映射为 smoothstep(0.01,0.08,coverage)，在原 <=0.01 discard 后使用。>=0.08 的像素显示稳定，0.01–0.08 连续过渡；零覆盖不填充、不访问相邻 UV 岛、不改变选区非零支持范围。相比原始覆盖，外缘显示过渡更窄，并非完全保留原透明度曲线。

累计 UV、投影及实时屏幕红条纹共用同一 helper。计算在加/减/反选组合完成后执行，不改变输入蒙版。场景深度测试、前后面通道、既有深度偏移和实时前表面裁剪保持；不以关闭深度测试解决缝隙。

GPU 审计：仅反馈着色器变更，累计 UV 写入和 Capture 材质不引用 helper；不新增 pass/纹理/采样/读回。CPU/Worker 无对应显示内核，不修改作者 mask、GPT 引导合成、绘制/擦除、持久化/历史、UV 回贴/导出、输出分辨率及 QA。Project Command/CAS/ownership/verified assets 保持，无 Schema/数据迁移。

## 验证

- 自动回归实例化三个实际显示材质，检查统一 helper、discard/深度/擦除/反选及捕获隔离；10001 个覆盖值验证零值、单调性、范围、稳定内部和柔和过渡。
- 用户车辆模型副本（1,999,546 三角形）独立 Edge WebGL：四视角、完整 mask/实际 512 UV 累积对照，不连接或改写用户工程。以导出有覆盖而显示红色不足一半统计，旧→新为 10001→312、14239→635、11378→536、104496→6096；采用统一不透明红色测量以去除条纹周期干扰，不能视为用户某笔实际选区的逐像素复现。
- 每个显示前后实际 Capture RGBA 逐字节相同，WebGL 无异常。实际条纹可见性还需用户原角度验收；零覆盖缺口与独立深度遮挡不在此次修复范围，不宣称全部 UV 裂缝消失或实测零性能成本。
- 正式 prepush、全 Web 回归及部署产物验证结果由发布记录确认，未提交付费生图。
