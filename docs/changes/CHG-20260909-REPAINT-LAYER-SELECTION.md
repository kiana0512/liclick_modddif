# 图层选择与局部重绘显示解耦

主模块 M08，协作 M06/M05/M12；维护版本 2.19.13。
生命周期契约 REPAINT-LAYER-SELECTION v1.0.0，实施 Codex，用户工程体验验收由维护者执行。

## 证据与范围

用户录像 20260909222944：两个图层眼睛保持开启，切换选中行时局部回贴内容短暂变化。代码中普通选中会恢复重绘编辑源，重启 source/overlay 准备；停用的 progressive compositor 仍以 active ID 生成新数组，使常驻材质 effect 失效；全量 layer store 订阅还会在只改选中 ID 时重新执行显示所有权交接。

回归直接执行生产 effect/React memo 和真实 Zustand 订阅。修改前 400 次普通选择产生 66 次编辑源发布，首先在“零源发布”断言失败。此为生命周期复现，不等同用户完整工程的逐帧像素验证。

## 修改

- 普通选中仅改变选中高亮，不通过 persisted-source 恢复接管重绘显示。显式橡皮擦仍在指针输入前准备目标；当前生图结果的后台预热、应用重绘入口保持。
- 异步蒙版编码完成时重新检查当前工具，离开橡皮擦后的迟到结果不发布。
- 全量 store 通知仅在 layers 引用改变，或橡皮擦活动时选中目标改变，才同步 overlay。眼睛、删除、顺序、mask、opacity 和撤销快照继续触发；只改选中 ID 不触发。
- progressive fallback 未启用时不将 active ID 纳入 memo 依赖，稳定实际材质依赖；启用时原前景/背景分组语义不变，不重新开启已停用降级路径。

## 一致性与验证

GPU 只改变资源准备/显示交接触发时机；shader、source alpha、深度、覆盖、UV、CPU/Worker 合成与导出不变。保留上版 MSAA 几何深度修复。无新增 Schema/持久化字段，不改 Project Command 幂等、Revision CAS、ownership、verified assets、分辨率或资产；无数据迁移，不清空历史。

新增 test:repaint-layer-selection：400 次普通选择不发布编辑源、100 次选择不重启交接、100 次选择不改变材质 memo 引用；保留橡皮擦切换/同目标复用、迟到编码取消、显隐/修改/删除、卸载监听释放，以及启用 compositor 时的原分组。原图层回归更新两条已被本契约替代的“空闲选择主动恢复源”断言，原编辑和显示断言保留。

冷加载历史图层首次开启橡皮擦可能仍需原有准备时间；本次不以普通点击时抢占显示换取预热，不宣称所有首次编辑均零延迟。完整工程连续选择的视觉验收待用户复测。
