# PROJECTED-SELECTION-PREVIEW/0.1.0 — 本地效果评审

主模块 M08，协作 M03，入口 UI-06。本文件记录一个未接入正式编辑器的独立原型，不是发布完成证明。

显示读取冻结屏幕笔画、投影矩阵、相机位置和深度，按原始顺序 source-over 添加、乘法擦除、最后反选。模型 UV 不参与显示；真实测试旁路仍调用现有 UV 累积材质生成 canonical mask。显示继承既有深度偏移和前后面门禁；投影深度按接收平面梯度校正到实际深度 texel 中心，保留 0.00002 epsilon，不能用关闭深度测试替代。

四槽固定 sampler/矩阵，最多四个快照（超限抛错，不静默丢弃或降级为 UV）；借用不可变纹理，复制矩阵/位置，材质释放不销毁借入纹理。生产接入前仍需解决长笔画合批/容量、显示与作者支持域差异、正式撤销/重做/反选/消耗选区、相机与对象变换、恢复旧 UV-only 状态、显隐和辅助层捕获排除、资源预算与性能门禁。不能只复制此 shader 就宣称编辑器功能完成。

已验证：同一 1,999,546 三角形车辆，UV/投影显示前后 UV target 字节一致；将全部模型 UV 改为零再恢复，离屏投影显示 RGBA 完全一致；按既有 UV 累积擦除/撤销得到原字节；转动不改 UV。鼠标可旋转观察，原始视角和转动视角截图独立保存。默认 framebuffer 的 MSAA 逐次截图有差异，UV 独立性对照明确使用单采样离屏 RT，未将其冒充默认 framebuffer 字节一致。

生产 GPU/CPU/Worker/shader/捕获/保存/远端输入/回贴/导出均未接入本模块，持久化、Schema、Command/CAS/ownership/资产、分辨率与 QA 不变。没有数据迁移；回滚删除未引用模块、测试和本地验证入口即可。此原型仅在本地效果页展示，master 和 A100 未更新。
