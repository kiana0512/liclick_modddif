# CHG-20260912-LOCAL-REPAINT-BRUSH-DEFAULT

## 2026-09-16 视口蒙版画笔默认值

- `PAINT-MASK-BRUSH-DEFAULT` v1.0.1：仅视口加选/减选使用的 `paintMaskSettings.brushSize` 从 45 改为 35。应用重绘画笔保持 30，独立画布及其他绘制/橡皮、羽化不变。
- 只影响新初始化；视口偏好持久化不保存该大小，刷新会采用新默认值，同次运行手动调节继续有效。
- 无 GPU/CPU/Worker/shader、半径公式、分辨率、历史、保存/导出或 Schema 变动，无项目/资产迁移。回滚默认常量为 45 即可。
- 回归检查初始蒙版为 35、应用画笔为 30、普通绘制为 32、橡皮为 42，且用户手动设置仍可修改。尚未推送或部署。

## 范围

- UI：UI-10 局部重绘工具。
- 主模块：M08 局部重绘。
- 设置版本：`LOCAL-REPAINT-BRUSH-DEFAULT` v1.1.0。

## 修改

局部重绘视口蒙版画笔和独立画布画笔的初始大小统一为 `30`。视口偏好持久化当前不保存局部重绘画笔大小，因此刷新后的新运行时会采用该值；同一运行时内用户手动调整继续保留，不被后台任务覆盖。本次只提取 91d3061 中的两个默认常量，不包含该提交的 Alt 导航改动。

## 不变项与迁移

- 不改变画笔半径换算、压感、羽化、加选/减选、GPU/CPU/Worker 像素公式。
- 不改变输出分辨率、历史、保存、Project/Layer Schema、Revision CAS、ownership、verified assets 或导出。
- 无项目或资产迁移。回滚时恢复两个默认常量，不处理用户数据。

## 2026-09-15 修订 v1.0.1

按用户要求，局部重绘视口画笔与独立画布画笔默认大小由 15 调整为 30。只影响新初始化的画笔设置，羽化、用户手动调节及其他画笔参数不变。无算法、Schema 或数据迁移；回滚两个默认常量为 15 即可。
