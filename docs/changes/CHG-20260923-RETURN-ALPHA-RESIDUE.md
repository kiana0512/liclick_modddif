# 返回图半透明背景残留修复

主模块 M08，协作 M06；算法 GPT-RETURN-BACKGROUND-CLEANUP/2。

实际 GPT 局部重绘回图 2048×2048 的主体边界只偏差约 1–2 像素，但远离主体的背景残留 alpha 达 166，触发 alpha>=128 轮廓检查；原连通分量清理未能处理。

共享还原路径先验证高置信主体（alpha>=200）边界，使用返回图自身主体包围框加 0.5%/至少 4 像素保护边距，清理边距外连通画布边缘的 alpha<192 残留。不会用输入蒙版裁剪返回主体，不修改 RGB，也不提高正常轮廓校验阈值。先规划与复核，最后提交 alpha 修改，取消不产生部分修改。未能通过复核时保留旧清理策略。

单视图、多视图和 GPT 局部重绘经 contentFramingRestore 共用清理；GPU、CPU、Worker 回贴及导出算法无需改变，仅消费清理后的图像。无需资产、Schema、CAS 迁移。历史失败不会自动重发；回滚恢复 v1 清理模块即可。

验证：3 次真实任务回图离线复现，失败样本由误拒变为通过，其他样本仍通过；覆盖半透明桥接残留、RGB 和主体抗锯齿保持、偏移/半主体/不透明背景/透明主体拒绝、取消不修改输入。尚未部署。
