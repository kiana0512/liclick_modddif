# CHG-20260912-GENERATION-RENDER-LIFECYCLE

- 主界面/模块：UI-05、UI-06 → M03、M04、M06
- 编排算法：`GPT-MULTIVIEW-PAIR-SEQUENCE` v1.2.1、`TEXTURE-RUNTIME-RESIDENCY` v1.5.0
- 目标：切换同项目模块或浏览器标签页时，单视图、多视图、局部重绘及其投影/合成运行时保持存活。

## 根因

多视图下一组输入必须包含上一组已经回贴的累积材质。旧路由切换会卸载 `EditorPage`、`GeneratePanel`、场景与 WebGL；浏览器标签页隐藏又会暂停 `requestAnimationFrame`。两者都会令已提交远端任务失去投影/合成消费者，最终把“远端结果已保存、但页面运行时已卸载或尚未呈现”错误归类为生图失败并停止后续视角。

## 修复与边界

- 从贴图工作区进入同项目 UV、重拓扑或烘焙时，保持同一个 Engine Session、Editor、GeneratePanel、场景和 WebGL 实例；只把贴图界面移出交互与合成层，不使用 `display:none` 或条件卸载。
- 前台贴图视口保持 `always` 帧循环；隐藏且有单视图/多视图/局部重绘或内容修复任务时使用 `demand`，隐藏空闲时使用 `never`，避免常驻运行时抢占交互帧预算。
- 所有生成入口仍可在任务进行时切换同项目模块；模型/图层等会破坏捕获一致性的编辑仍由原冲突锁保护，离开项目、切换项目、注销和刷新仍保留明确终止/告警边界。
- 后台标签页不再等待“恢复前台”才推进呈现检查。统一 paint 调度在前台使用 rAF，在后台使用有序任务回退；Runtime depth/normal 的两阶段提交也不再直接等待裸 rAF。
- 生成任务持有低频渲染 lease：同页其他模块下每 50ms 唤醒 demand 帧；只要浏览器标签页 hidden，或 LI3D 窗口失去焦点/被其他窗口遮挡，就每 250ms 尝试由 R3F `advance` 运行同一组 `useFrame` 订阅与渲染。前台且获得焦点的 active 贴图页不启动额外 lease 定时器。Resident UV 新请求也显式 `invalidate` 首帧，避免直到返回贴图界面才启动合成。
- 投影纹理数组预编译、GPU fence 轮询、普通 UV 合成和 Runtime visibility 修复不再直接等待裸 rAF；统一走前台 rAF、后台任务回退的 paint 调度。标签隐藏时直接释放仅用于避免抢占鼠标/画笔帧的交互等待，但仍等待真实 shader 编译、GPU fence、纹理上传与材质提交完成。
- Resident UV 合成不再把 `useFrame` 作为算法启动器。新图层签名请求到达后由微任务立即启动 `step()`，并以有界后台任务 lease 驱动暂时错误重试；前台指针交互仍保留让帧，hidden/失焦时立即计算。因此任务栏预览小窗不再是启动 UV 算法和继续下一组的必要条件。
- GPT 配对与 Resident UV 屏障保持等待直到真实材质绑定/合成完成或底层发布真实错误，不以本地墙钟把已成功 Generation 改写为失败。
- 呈现等待超过前台预算时只显示“结果已保存，等待回贴与合成渲染”，保持严格屏障并继续等待，不改写成功的 Generation。
- 左侧参考图下方仅不渲染“本组回贴后再生成下一组 / 等待回贴与合成渲染完成”这两类长等待文本；其他普通进度、警告和错误仍正常显示。严格等待、恢复、回贴和下一组顺序未删除。
- 远端轮询不再以浏览器本地 30 分钟墙钟判失败；暂时网络错误自动重连。仅远端明确 `failed`、任务明确不存在、工程/模型改变、用户终止时进入失败/停止路径。
- 不跳过渲染、不提前截取、不以旧画面继续下一组，也不在后台伪造“已呈现”；输出分辨率和 QA 不降低。

投影、UV、合成像素、GPU/CPU/Worker/shader、分辨率、QA、Project Command、Revision CAS、ownership、verified assets 和导出协议均不变；无 Schema/资产迁移。

## 验证

- GPT 编排动态回归验证后台生命周期不依赖前台可见性、必须完成两次呈现确认才继续，以及长时间呈现只告警不失败。
- 远端多视图顺序回归验证每一张仍必须 `addGenerationAsProjectedLayer` 并等待 resident 事件后才增加完成计数。
- 常驻路由回归覆盖同项目 UV、重拓扑、烘焙以及跨项目/离开工程释放；视口策略回归覆盖 always/demand/never，并静态验证 hidden、window blur/focus 都能重启渲染 lease。
- 单视图、多视图、局部重绘后台调度、Resident UV、TypeScript 与全仓回归随本次审计执行。

## 回滚

移除 App 常驻分支、恢复生成期间模块导航拦截、恢复固定墙钟和前台等待即可回滚，但会重新引入页面切换导致成功结果被误判失败的问题。无持久数据迁移。
