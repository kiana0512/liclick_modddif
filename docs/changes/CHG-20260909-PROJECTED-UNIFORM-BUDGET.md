# 投影材质参数上限保护

主模块 M06，ALG-PROJ-007 v2.1.7。

现场证据：34 个投影输入的材质链接失败，浏览器明确报告 `FRAGMENT shader uniforms count exceeds MAX_FRAGMENT_UNIFORM_VECTORS(1024)`，不是模型文件丢失。纹理数组只解决 sampler 数量，不解决逐层矩阵和控制参数上限。

新增保守参数预算（每层 32 个向量槽、公共参数保留 128 槽），按设备 maxFragmentUniforms 决定是否可以提交整个材质。超限走已有分批预览合成，不截断图层，不降低分辨率；预热也检查同一预算。等待完整预览期间显示持久提示，建议合并 UV，完成后清除提示。

该预算仅用于视口调度。GPU/CPU/Worker、合并 UV、导出、资产、图层保存、CAS 和 ownership 语义不变。分批预览仍需在实际模型上核验效果，不能以不再链接失败替代像素正确性验证。

验证：34 层/1024 槽拒绝、14 层/1024 槽允许、14 层/256 槽拒绝；编译生命周期及投影性能回归通过。没有 schema 迁移。回滚预算接入和提示即可，但会重新允许提交超限材质。
