# CHG-20260914-TIGHT-CAPTURE-FRAMING

- 主模块：M03；协作：M04/M08/M06；算法：ALG-CAP-007，1.0.0 → 1.1.0。
- 问题：世界轴包围盒包含大量投影空区，机器人斜视截图主体偏小。纹理与白模分别拟合也可能产生相机不一致。
- 行为：扫描 drawRange 内提交的几何顶点，忽略未引用索引顶点及 viewport helper；在原视角/FOV 下求透视距离与横向中心，正交调整投影范围。限制尺寸目标 92%，各边约 4% 留白；纵深安全距离具有优先级。
- 检查：最长边 256px 白色轮廓确认边缘 2.5% 安全区和非空结果；最终输入仍按请求分辨率重新渲染，临时蒙版及时释放。空几何、非有限坐标、InstancedMesh/SkinnedMesh/位移贴图、超过 200 万提交顶点或校验不可用，回退原保守取景。扫描协作让帧并检查取消。
- 对齐：单视图与局部重绘复用提交快照；多视图每角度冻结，GPT 成对输入和远端顺序补全都复用对应相机。明确 cameraSnapshot 时不再二次 fit-object。局部重绘继续从作者 UV 蒙版按新相机重捕获。冻结相机按现有 Capture 序列化用于投影。
- 对应路径审计：GPU/CPU/Worker/shader 继续消费已有序列化矩阵；UV、蒙版坐标、持久化、历史恢复、导出格式和投影公式不变。无 Schema 或资产迁移；旧 Capture 保留旧矩阵。
- 打包：取景模块静态并入编辑器，减少异步模块重复依赖声明；共享目标网格筛选规则，不提高包体预算。正式发布构建额外精简八角点枚举、用包围盒半尺寸点积计算投影范围，并消除水平 FOV 的 atan/tan 往返；600 组旧/新回退相机矩阵对照误差小于 1e-8。
- 验证：72 组透视/正交、极点、宽高比、远近和不可变快照；12 组细长突出部件和未引用顶点；空蒙版/边界触碰回退及临时资源释放；GPT 成对截图快照契约。前端 124 项回归、类型检查、生产构建和包体门禁通过；最终检查记录见工作区日志。
- 实际 GPU 样图：本地“工业风金属切割机模型.glb”，309126 个索引顶点，六个角度均未触发回退。2048px 斜视角高度占比 65.82% → 91.99%，宽度 52.44% → 74.80%。样图使用本地蓝绿色原材质，不代表用户未导出的黄色投影贴图；没有提交付费远端生成。
- 回滚：一并恢复 generationFraming/captureCurrentView/GeneratePanel 的相机传递和旧拟合路径，删除 tightCaptureFraming；目标筛选 helper 可保留。无需清理历史或迁移已生成图片。
