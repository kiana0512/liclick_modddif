# 生图期间允许删除图层

- 主模块 M05/M04；协作 M08/M12；策略 GENERATION-LAYER-DELETION v1.0.0。
- UI-05 图层面板与编辑器事件门禁；基线 405f7f5；维护文档 2.19.9。

## 范围

生图等待时支持菜单删除、多选删除及原带确认的一键清空。删除采用单独 deletionLocked，不解除模型删除/替换、合并图层、图片替换等其他 mutationLocked。快照、局部重绘输入准备/启动交接以及内容识别填补仍保护输入；请求已冻结输入后允许删除。局部生图返回仍是新的生成结果，不会取消任务或修改已发出的截图。

全局捕获仅放行图层行选择、菜单入口和显式删除按钮；不把整个面板加入预览白名单。键盘 Delete/Backspace 在任务期间只允许焦点位于图层区域，输入框继续正常编辑，模型区域继续保护。

## 历史和并发

沿用原 captureHistory、选中项清理、重绘行及隐藏目的层成对删除、live source/overlay/画笔清理及下一帧行删除。未删除的图层保持原 ID 与内容，撤销仍使用原操作记录（原生图期间撤销快捷键锁不改变，解锁后可撤销）。已删除图层对应的历史生成资产仍可查看，不物理删除文件。

发现关键保存此前可能在持久化资源及 CAS 重试后使用旧 layers 覆盖在线删除。现在每次 CAS 变更器从当前项目实时 layer store 读列表；切换项目则保持原目标项目输入，不混入另一项目。已存在目标图层在图片保存期间被删除的原防复活检查保留；新任务生成的新图层仍正常追加，不恢复旧图层 ID。

## 验证与管线审计

专项回归执行实际删除回调：保护阶段无变化、生成等待删除普通/局部重绘、去重/无效 ID、关联层清理及一条历史记录。实际 CAS payload producer 覆盖上传后删除、重试后再次删除、清空及项目隔离；原冲突锁回归保留其他操作门禁。UI 属性检查覆盖菜单单/多选删除、清空、作用域快捷键和输入准备状态。

验证结果：100 项 Web 回归、TypeScript、变更文件 ESLint（0 错误，8 项既有警告）和 diff 检查通过。Edge 挂载真实 LayersPanel/Actions 与事件门禁夹具，验证菜单删除、焦点内 Delete、多选删除、清空确认、焦点外 Delete 不删、复制仍锁定及输入保护阶段禁止删除；无 pageerror。夹具不是完整用户工程或真实付费生图端到端验收。

未改变 GPU/CPU/Worker/shader 像素公式、UV/export、输出分辨率、质量门禁、项目 Schema、Command 幂等性、ownership 或 verified assets。仅调整 UI 策略与最新图层快照读取；无迁移。回滚本策略/接线/保存读取修改即可，不删除资产。本次尚未提交 master 或部署 A100。
