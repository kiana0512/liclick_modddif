# UV 回读延迟与图层显隐扫描

主模块 M07，协作 M03/M06/M08/M09。UV-READBACK-SCHEDULING/1.2.0；UV-READBACK-SCAN/1.0.1。

4517 cooler / 4K 单独隐藏底部投影层：眼睛立即变更，UV 最终呈现耗时 572.5ms；回读及精确修正 223.1ms，其中完整回读 162.8ms，转换 53.5ms、接缝 11.7ms、gutter 81ms、底图混合 120ms、上传 55.2ms。各阶段有包含关系，不相加冒充净时长。该操作未新增 50ms 主线程长任务，响应延迟仍明显。两层交替切换后恢复全部十个投影层可见，最终 ready、processedLayerIds 与眼睛状态一致，无缺失层；未据此声称任意操作无竞态。

修改：独立渲染器改成四个 2MiB 分段并发，可见渲染器仍为一个 1MiB 分段并保留绘制让步。在途 PBO 最大仍 8MiB；异步失败继续排空在途任务再释放目标。GPU-order RGBA 使用整数掩码识别原精确修正标记；Worker 的原位翻行、coverage 和弱透明索引扫描按同一个 RGBA 字读取，减少重复字节访问。沿用既有小端 RGBA/uint 契约，不改标记、Top-K、CPU canonical 修正或最终颜色公式。

真实 WebGL 对照：同一 4096×4096 RGBA 纹理，1MiB/8 与 2MiB/4 交替四轮，原方案 105.4/90.4/90.6/92.5ms，新方案 76.0/71.6/77.7/76.6ms；两者帧间隔峰值约 16.8ms。每轮完整 67,108,864 字节对照零差异，不仅检查抽样/摘要。此为独立回读阶段，不能称整个 UV 合成或冷启动已提速相同比例。

修改后 4517 真实项目重新加载、首次隐藏左侧投影层：完整呈现 2421.1ms，其中回读 83.2ms（32 段，单段峰值 22.7ms）。这次没有 GPU 光栅缓存，另有校准、拓扑、源图准备与上传，不能与修改前暖缓存的 572.5ms 总耗时直接比较。首次新组合仍慢，后续需要独立处理；恢复左层后十个投影层均可见。独立图层选中切换录制 60 FPS、P95 16.8ms、无长任务，仅代表该次选中操作。

确定性回归覆盖矩形/奇数尺寸/末段、目标字节偏移、缓冲上限、倒序失败与清理；标记相似颜色不能误修正，既有舍入/重复候选/alpha 模式回归通过。Worker 逐字节 RGBA、coverage、弱透明索引、原位所有权回归通过。Node 4K 转换五轮中位约 41.6→39.8ms，仅局部小幅收益，不冒充浏览器总耗时。

GPU/CPU/Worker/shader 均保留原输入输出与完整质量验证；正式投影/UV 产物、采样方向、输出分辨率、生成呈现屏障、持久化、导出、Command/CAS/ownership/verified assets 均不变。无 Schema/资产迁移。回滚恢复独立上下文八个 1MiB 段和逐字节扫描；资源处置及失败排空不能移除。
