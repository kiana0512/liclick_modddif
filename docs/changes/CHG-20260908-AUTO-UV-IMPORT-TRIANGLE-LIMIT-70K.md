# CHG-20260908-AUTO-UV-IMPORT-TRIANGLE-LIMIT-70K

- 日期：2026-09-08
- 主模块：`M10` UV 导入与展开
- 界面：`UI-14`

## 问题与修改

UV 页导入模型时的前置保护原为 20,000 个三角面，无法接收用户需要处理的中等规模低模。本次将 `AUTO_UV_MODEL_TRIANGLE_LIMIT` 调整为 70,000，并把限制文案改为根据真实阈值格式化，超限时显示“7 万面”。

## 边界、验证与回滚

- 70,000 面及以下允许进入后续 UV 流程，70,001 面及以上继续在解析后、提交前拒绝并释放模型资源。
- 贴图工作区的 2,000,000 面限制和本地 UV 内核的 2,000,000 面安全上限不变；不修改 UV 展开算法、加载格式、导出、Schema、Revision、ownership 或资产，无数据迁移。
- 回归覆盖 7 万及 200 万提示、边界计数与通用阈值格式化；回滚只需恢复入口常量和文案，不处理既有工程。
