# CHG-20260922 — 统一 ModelView 参考分流与后台去光照

主模块 M04（协作 M13/M12/UI-05）；算法 `MODELVIEW-REFERENCE-ROUTING/2.0.0`、`REFERENCE-LIGHTING/2.0.0`。

## 行为

- 局部重绘、ModelView 单视角和多视角贴图统一请求 `/api/v1/services/modelview-inpaint`。参考图角色显式转换为 `reference_view_count=1` 或标准六视图的 `6`，不根据生成视角数、尺寸、文件名猜测。
- 单视图参考保持单视图，取消生成前自动补六视图。手动生成多视图按钮保留。白模首次生成使用同机位模型 mask；已有贴图补全保留缺口 mask 和原合成策略。
- 导入/恢复参考图时后台启动一次共享去光照。客户端以用户、项目、参考 ID、源文件内容 SHA 和算法版本去重。处理图不进入 UI 参考列表，生成请求等待并使用处理结果。已有双阶段去光照结果标记 `lightingProcessed=reference-delight-v1`，不二次处理。
- 复用现有鉴权、个人账号和持久化 LiClick 任务。后台任务不占前景任务互斥锁、不进入前景历史列表；轮询/网络失败复查同一 job，不自动创建新收费任务。
- 完成后保存参考资产以及私有绑定索引；项目目录 `.reference-lighting` 的 JSON 同时保留资产引用，纳入既有存储扫描。索引按用户隔离，项目不存在时不读取绑定。普通任务日志裁剪后仍可恢复完成结果。
- 返回项目时增加“图片正在处理中，是否要中断”；生成中沿用原取消确认，后台图片处理可单独确认中断。刷新/关闭页面使用浏览器标准离开提示。中断停止客户端等待及后续提交；既有 LiClick 取消端点标记任务终止，不保证取消已分配的远端 GPU 运算。
- ModelView 网络错误或 504 最多重放两次，复用冻结 multipart 字节和幂等键。404/409/422 不自动重试。无 noise_seed；记录 job、SHA、项目、计数、完成时间。

## 对等审计 / 迁移

此次为请求编排变更。GPU/CPU/Worker/shader 的投影、选区、UV 像素、导出分辨率不变；保留同机位 capture/mask/normal、单视图补全渐变合成。Project Command/CAS 未旁路。ReferenceImage 新增可选处理版本标记，旧项目无需迁移；旧参考首次使用进入处理，旧 generation 不改写。

回滚代码即可恢复旧请求入口及自动多视图路径；已生成图层保留。私有绑定和参考资产可保留，不删除用户数据。

## 验证

- 前后端类型检查、Web lint、生产构建。
- ModelView HTTP mock：1/6 分流、非法/缺失计数 422、四图、同幂等键同字节、法线/蒙版尺寸校验、PNG 保存和原补全合成。
- 前端真实调用函数回归：两个贴图入口均按参考角色发送计数，蒙版/法线原样传输；逐视角准备、驻留、取消边界保留。
- 参考处理回归：并发去重、原图不变、内容相同换 URL 不重付费、页面重载、账号隔离、取消单个等待者和明确中断后新尝试。
- 原双阶段六视图/光照处理、绑定恢复和生图锁回归。
- 新异步处理模块使本地 JS 总量从约 3,261,694 增为 3,267,498 bytes。总预算有界增加 6,500 bytes 至 3,268,500；其他 chunk 预算和 QA 门禁保持。
