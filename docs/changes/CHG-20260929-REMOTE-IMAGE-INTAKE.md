# 服务端远端图片读取边界

- 日期：2026-09-29；状态：待正式门禁和生产复验。
- UI/use case：UI-05 莉刻局部编辑返图、M02 远端图片资产导入；M02 主模块、M13 安全协作；`REMOTE-IMAGE-INTAKE/1.0.0`，Patch，无图像算法变更。
- 输入：上游返图 URL 或用户提交的受支持远端图片 URL。输出：原始图片字节与 MIME；局部编辑结果继续按原协议转换为 data URL。
- 风险和根因：编辑返图之前可由服务端直接 fetch 任意 URL，且没有超时、类型或大小限制；资产导入虽检查初始 HTTPS 域名和声明长度，但默认跟随重定向并一次性读取完整响应，缺失长度的响应可先占用大量内存。
- 规则：仅标准 HTTPS、明确允许的域名和无嵌入式账号 URL 可发出网络请求；内联 `data:image/` 在读取前限制编码长度；最多跟随三次逐跳校验为白名单 HTTPS 的重定向；统一 30 秒超时、`image/*` MIME、160 MiB 声明长度与实际流大小门禁。超限不会生成资产或返回不完整结果。
- 六路径：本补丁不改投影、UV 合成或局部重绘像素语义；GPU/CPU/Worker/shader、持久化、导出算法不适用。已有结果的像素、颜色空间、分辨率、Project Command、Revision CAS、ownership 均不变。
- 验证：独立回归覆盖内网/HTTP/非白名单域名、非标准端口、URL 账号、危险/白名单跳转、MIME、声明超限、无长度分块超限、正常图片和内联图片；server lint/typecheck、全仓正式门禁。生产上游真实域名与耗时仍需健康监控。
- 迁移/回滚：无 Schema 或历史资产迁移。若新上游改用其他域名，须在 `LICLICK_ALLOWED_REMOTE_ASSET_HOSTS` 明确配置并验证；回滚代码会恢复无界下载风险。
