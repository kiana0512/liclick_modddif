# UV 合成与内容修补的快照复制

主模块 M07，协作 M08/M09/M12；UV-SNAPSHOT-COPY/1.1.0。

完整 4K 合成基准中出现 finalize-complete 长任务，包含大块 RGBA 快照复制和缓存写入。将完成后的只读投影/缓存图像复制改成 1MiB 段、约 4ms 让步并遵守视口交互门禁，复用到合并准备、最终 PNG 准备、显式合成和内容修补。等待结束前不会返回部分图像，调用方仍获得独立可写副本；支持准备任务的取消检查。输入必须是已完成的不可变烘焙结果，不用于仍在绘制的画布快照。

保持全部 RGBA（含透明 gutter RGB）、尺寸、排列、CPU/Worker/GPU/shader 算法及 QA；未修改 PNG、持久化字节格式、Project Command/CAS/ownership 或导出。缓存写入仍按原 SHA-256 验证协议执行，不能把本次复制优化描述成已解决所有缓存写入长任务。

测试：完整 4096×4096 RGBA 字节对照、偏移视图、独立所有权、63 个负载下让步边界、取消不返回半成品；合成准备去重、输入失效、底图顺序、最终 PNG 复用与原生 UV 回归通过。真实多轮基础测试记录另见验收卡。无 Schema/资产迁移。回滚恢复同步克隆及原调用点；不得删除像素校验和恢复逻辑。
