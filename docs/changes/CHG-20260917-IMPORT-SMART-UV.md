# 导入修复改为智能 UV 投射

- 主模块 M02，协作 M10/M13；IMPORT-UV-REPAIR v1.2.0。用户明确要求修改并推送 master、部署 A100。
- 用 bpy.ops.uv.smart_project(angle_limit=66°, island_margin=0.001) 代替 ANGLE_BASED 展开及旧手动切缝。保留平均岛尺度、共同排布 margin=0.001、按实际包围盒补足 1e-6 外边界。
- FBX 转出的非索引 GLB 会把三角面拆成独立顶点，直接投射仍会产生极碎小岛，甚至导出 Float32 退化。每个对象建立仅用于 UV 的临时网格，以完全相同的局部坐标建立连接；没有距离焊接，也不跨对象合并。智能投射后按原面和面角回写 UV，检查面角坐标与数量一一对应，再删除临时网格，只导出原模型。
- 原模型几何、材质分区、面角法线不由该操作重建。保留 Blender 自身导出回读的数值转换；不承诺与输入 GLB 法线逐位一致。导出前新增原三角面总数检查，导出回读继续验证 0–1、有限值、非零面积和三角形数量。
- 现有用户确认、认证、超时/取消、临时目录回收、源文件和旧项目保护保持。只有导入检测异常且用户确认才调用。没有增加导入检测条件，不自动重展存量工程，不恢复拓扑减面。
- GPU/CPU/Worker/shader、投影/等待流程、UV 烘焙 QA、完整分辨率、蒙版/深度、持久化/export、Schema、Command/CAS、ownership、verified assets 不改。无数据迁移；旧的错误 UV 需要从源模型重新导入处理，现有项目不会自动修复。
- 回滚：恢复该 Blender 脚本及版本；保留已修复模型资产，回滚不会自动恢复原 UV。

## 验证

- A100 Blender 5.1.2 隔离运行生产脚本：原问题模型 400162 个三角面保持；UV 越界、非有限、退化均为 0。面积总和由 0.0001691882 提升到 0.2844260381。
- 几何逐三角形坐标哈希与输入一致；与同版 Blender 普通导出回读基线相比，面角法线最大差异为 0。可复核：node apps/server/scripts/check-import-uv-smart-result.mjs baseline.glb smart.glb。测试文件不写入工程或仓库。
- 真实浏览器加载修复 GLB，使用原项目的前后生成图、冻结相机、mask/depth，在 2048 分辨率运行正式 GPU UV 内核，写入 511554 个有效像素，覆盖率 0.121964；未改阈值或启用 legacy fallback。
- 验证及发布记录以最终提交的 verify:prepush、线上 release SHA 与服务健康检查为准。
