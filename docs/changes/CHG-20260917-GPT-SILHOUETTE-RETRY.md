# GPT 返图轮廓漂移单视角有界重试

- 日期：2026-09-17
- 主模块：M04；协作模块：M03 / M06 / M08 / M12 / M13
- 算法：`GPT-RETURN-SILHOUETTE-QA/1.2.0`、`GPT-SILHOUETTE-RETRY/1.0.0`、`ALG-GEN-001/002` v1.3.1

## 现场结论

保留的“前下 45°”2K 结果不是客户端误拒绝。按冻结捕获框还原到生成方图后，预期主体纵向约为 `272..1778`；远端结果 `alpha >= 128` 的外框为 `0,272..2047,2047`，在预期主体底部之外额外生成了大面积半透明背景/光晕，使 Alpha 底边外扩约 269 px 并超过现有 12% 容差。这足以证明返图透明轮廓错误；单凭 Alpha 外框不额外推断主体本身已下移或放大。放宽门禁会把这些错误颜色投到模型上。

## 修复

- 轮廓 QA 保持 fail-closed；尺寸、空 Alpha、明显缩放/平移仍拒绝，不用冻结 capture mask 掩盖远端构图漂移。
- 将轮廓不匹配升级为稳定错误码，只对该错误执行一次同视角替代任务。网络错误、账号/额度错误、用户取消、投影失败及其他生成错误都不触发此重试。
- 替代任务复用同一冻结 Capture、相机、模型图、材质参考、分辨率和质量，提示词只追加“逐像素保持透明轮廓、禁止背景/光晕/裁切”的恢复约束。
- 重试任务 ID 由原任务 ID 确定性派生；服务端现有任务表按用户、工程和 workflow 复用同 ID，刷新/重连不会再次创建付费任务。
- 重试上限固定为 1。首次异常结果与替代任务分别保存；第二次仍不对齐时保留两次结果、停止回贴并显示明确错误。成功的同组兄弟视角仍按原顺序提交和回贴。
- 重试在原任务已经终态后才提交，不扩大每组并发上限，不形成多用户重试风暴。
- 提交时的 framing 和返图恢复/轮廓 QA 拆成按需分包；重试对象构造也从 Editor 热包下沉到异常时才加载的策略模块。生产构建实测 Editor 余量 `1034 B`、framing 余量 `1005 B`、总 JS 余量 `35449 B`，未调高任何预算。

## 不变项

- 不自动仿射缩放错位结果，不降低分辨率，不关闭轮廓 QA，不改变 capture mask、depth/normal、相机或投影/UV 权重。
- GPU / CPU / Worker / shader、PNG 像素、内容填补、保存/export、Project Command、Revision CAS、ownership 与 verified assets 不变。
- Generation 使用现有 `metadata: Record<string, unknown>` 记录 `silhouetteRetryOf` / `silhouetteRetryAttempt`；Project Schema 无新增必填字段，无存量数据迁移。
