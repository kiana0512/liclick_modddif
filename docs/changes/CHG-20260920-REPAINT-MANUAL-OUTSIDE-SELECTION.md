# 手动局部重绘范围与融合边界

## 范围与原因

- M08，审计 M06/M07/M11；ALG-LR-008 manual scope v3.1.0。
- 用户要求恢复生成蒙版外的手动局部重绘，并明确融合内缩针对实际绘制区域，不是生成蒙版。选中状态/新建图层提示明确不改。
- v3.0.0 为防暗边把生成作者蒙版同时作为手动画笔权限，导致原蒙版外 alpha 为零。源透明边界采样修复本身保留，不整体回退该版本。

## 实现与对应路径

- CPU 与 falloff Worker 共用 `createManualRepaintFalloffPixels`：有效冻结作者选区仅验证来源；输出中性白色权限纹理，不从其边缘推导手动画笔融合，也不按选区重心径向衰减。空/透明/黑色选区仍 fail-closed。原输入不改写。
- ViewportCanvas 原生 UV、兼容 Canvas 以及主线程 Worker 失败回退均使用这一手动核。缓存标识升级 `manual-brush-scope-v3`，不复用旧有限权限结果。
- 原生 UV 现有 shader 按当前真实笔迹距离及画笔羽化值向内过渡；未触及区域零写入。兼容 Canvas 的 inward blend 输入仍为 `composite.maskContext`（累计笔迹），不是冻结生成蒙版。两条既有融合公式和宽度不改。
- 自动生成输入/回贴流程及 bounded helper 不改；实际 Worker 仅服务手动画笔准备，不再加载无关距离变换核。
- 源图 alpha、生成相机及深度、当前可见面、实际笔刷覆盖继续约束写入；保留原生 UV 透明背景预乘取色保护。模型轮廓 3px@2K 的源 alpha 保护是另一个步骤，本次不改。
- GPU/CPU/Worker/shader 输出仍为原分辨率 UV RGBA，保存、撤销重做、图层合并、PNG/模型导出消费同一实际像素，无额外导出分支；Command/CAS/ownership/verified assets、Schema、QA 均不改。

## 验证与限制

- 单元：96 组内向融合像素对照、120 组阈值/透明度 fuzz、完整/局部 Canvas adapter；新增生成选区位移不影响手动权限、旧选区外/孔洞可画、空选区拒绝、实际笔迹作为融合输入的回归。
- 原生 UV、结果合成、笔迹选区消费、图层保留回归通过。
- Web TypeScript、变更文件 ESLint、Cloud/performance-lab 生产构建及原包体门禁通过：总 JS 3,254,528 / 3,256,500 bytes（余 1,972 bytes），含 256-byte 余量检查；未提高预算。构建未注入正式发布身份，发布时仍需完整门禁。
- 隔离 Edge 真实 WebGL：24 组平面/圆管、0/45 度、源 alpha/蒙版/手动画笔对照；新采样透明源外溢和黑边均为 0，旧负对照可复现 240–480 暗像素。Worker/CPU alpha 一致，PNG 回读及撤销重做像素一致。
- 新增真实小画笔完全落在原作者选区外：560 个不透明核心像素、1220 个内向过渡像素，实际画笔外零覆盖，证明融合边界跟随笔迹而非原生成选区。
- 未在用户在线工程落笔、刷新或重跑付费生成；自动夹具不等于用户原工程视觉验收。未推送、未部署。

## 迁移与回滚

无需资产迁移；已有 UV 像素/历史保持原样，重新进入画笔后新笔迹使用新规则。回滚仅恢复手动 falloff 的调用、Worker 核及缓存标识；保持透明边界 shader 修复，不删除图层或历史。
