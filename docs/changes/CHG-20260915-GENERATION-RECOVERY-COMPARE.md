# 生图历史同步直接比较字段

- 主模块 M12，协作 M04/UI-05；GENERATION-RECOVERY-COMPARE/1.0.0。
- 根因：每轮历史恢复对候选、工程记录和活动记录分别 JSON.stringify，其中 resultUrl/resultUrls 可能携带数 MB 图片；普通相机操作也会被轮询任务打断。
- 修复：相同的恢复字段采用直接比较，引用相同立即结束；引用列表/结果列表按值比较，不复制或序列化图片，不改变状态恢复、身份、错误和已提交图层规则。算法位于独立服务，React 只调用。
- 验证：所有原比对字段逐项变化仍识别；8 MiB 内联图片的相同结果做 1000 次比对时禁止 JSON.stringify 仍通过。独立 Node 同一输入 20 次，旧序列化约 546ms、新比较约 0.21ms；这是纯函数成本，不作为浏览器帧率承诺。
- 审计/回滚：没有像素、分辨率、GPU/CPU/Worker/shader、QA、UV/回贴、资产、Command/CAS/ownership 或导出变更，无数据迁移；恢复旧签名比较及调用即可。
