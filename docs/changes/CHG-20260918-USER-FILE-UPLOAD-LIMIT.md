# 手动上传单文件 100MB 上限

- 主模块 UI-04/UI-05，协作 M01/M02/M04/M10；USER-FILE-UPLOAD/1.0.0。
- 浏览器原始用户文件使用 `File.size > 100 * 1024 * 1024` 拦截，统一错误提示“文件大小超过 100MB 限制”。恰好上限允许，多选按每个文件判断，有超限文件则整批停止，避免部分导入和配套资源缺失。
- 在 FileReader、模型/图片解码、项目状态更新和上传之前执行。覆盖编辑器模型与外部资源、工程 JSON、参考图导入/拖拽/粘贴、图层图片替换、两个参考图面板、Bake 高低模/材质/Cage，以及 UV/拓扑资产处理单文件、多模型和参考图片选择。
- 内部生成返回、历史资产恢复、自动保存、模型处理的内部转换输出和远程 URL 不属于原始用户文件选择，不改其既有大小限制。未将服务端共用资产接口改为 100MB；本次是用户上传入口策略，不是可抵御绕过前端的服务端安全限制。
- 不改 GPU/CPU/Worker/shader、像素、分辨率、上传协议、Project Schema、Command/CAS/ownership/verified assets，不迁移或删除历史文件。既有项目包含超过上限的资产仍可恢复。
- 定向测试执行真实共享规则与 14 个入口首条门禁，覆盖恰好上限、超限 1 字节、多文件不累加、整批拒绝及提示；Cage 独立入口也覆盖。类型检查通过。
- 回滚删除 UI 入口门禁与共享策略即可，无数据回滚。本次未推送或部署。
