# 生成前统一取景与屏幕相机过渡

- 基线：master 0f0bf96；主模块 M03，协作 M04/M08。
- 算法：ALG-CAP-007 v1.0.0；复用已有单视图 createFitObjectCamera，整体对象包围盒，fillRatio=0.88。
- 用户授权：单视图/局部重绘生成前，用户视口相机也自动适配并以动画过渡；质量、正确性、性能必须保持。

## 行为与边界

保留观察方向、roll、透视 FOV/zoom。透视沿该方向调整距离并居中；正交通过 zoom 对齐截图的垂直范围，保留屏幕自身画幅。使用已有深度感知八角点算法，非截图裁切或图像缩放。单视图既有离屏取景规则不变，多视图预设不改变。

屏幕相机 240ms smoothstep 过渡，仅更新相机/控制目标；不在动画帧遍历模型、读回 GPU、捕获图片或触发 React 状态更新。开始/结束各通知一次控制器，开始清理滚轮惯性。隐藏标签使用已有呈现调度 fallback，避免永久等待。用户改变相机或取消即中止，保持用户位置，不再提交此次任务。动画后所有输入共用冻结相机。

局部重绘沿用已有 canonical UV mask 捕获：原始蒙版不改变，投到新相机；当前效果、白模、深度和 Capture 使用同一相机。没有可用 UV 捕获函数或捕获返回空时拒绝提交，不拿旧二维 mask 填补。投影/UV/CPU/Worker/shader/export 使用原序列化相机、mask 和 depth，算法公式不变；无新资产格式、分辨率降低或 QA 裁减。
