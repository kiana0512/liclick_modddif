# UV 读回减少主线程中转

主模块 M09；ALG-UV-008 v2.0.1。只改变内存目的地，不改变像素算法。

原读回每个 8 MiB 条带分配数组，再复制进最终完整 RGBA。现在用最终数组的 subarray 作为 Three.js 异步 GPU 读回目的地。分块大小、逐条 await、绘制让出、方向、质量与 Alpha 均保持。每个 4K RGBA 读回少分配和复制 64 MiB；GPU PBO 和最终完整结果仍需分配，不称零内存读回。

验证：真实 WebGL 4K 非对称渐变，八条带对照整幅读回，67,108,864 字节差异 0；2K 同样通过。自动回归覆盖非整除尾条带、buffer 身份、字节偏移、前后台让出和错误传播。类型检查与修改文件 lint 通过。总合成耗时与原项目交互提升尚未测定。

GPU shader、CPU/Worker 转换、投影/拓扑修补/UV/导出与 PNG、分辨率、QA、资产/CAS/ownership 均不改。无数据迁移；回退目的地为临时数组并恢复 set，或整体还原 helper 提取即可。不修改用户项目。
