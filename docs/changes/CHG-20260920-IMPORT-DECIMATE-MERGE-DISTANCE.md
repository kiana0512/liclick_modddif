# 高模导入：减面前按距离合并顶点

- 日期：2026-09-20；基线：90eb9ab8；模块：M02，协作 M10/M13。
- 算法：IMPORT-DECIMATE v1.0.2 → v1.1.0。
- 状态：本地实现与验证完成，未推送、未部署。

## 行为与范围

仅在模型导入总三角面严格超过 1,500,000、用户同意改变拓扑后生效：逐对象合并顶点 → 原 COLLAPSE 减面（约 200,000 面）→ GLB 导出回读 → 前端 UV 检查。异常 UV 仍须单独确认后才重展，不新增自动授权。

使用 Blender 编辑模式 remove_doubles，threshold=0.0001，与现有导入展 UV 流程一致。这是对象本地坐标单位，不是固定世界空间毫米；不跨对象焊接，不另行变换模型比例。GLB 导入已有的 merge_vertices=True 保留，但不能替代显式按距离合并。确认框明确说明合并与简化会改变网格、可能影响细节或原纹理。

合并可能消除退化或重复面，因此预算分配及 modifier ratio 都改用合并后重新统计的面数；合并后已在预算内时不继续降低面数。每对象须保留非空三角表面、有限坐标，面积比例 [0.99,1.01]；原减面及序列化回读面积保护、输出面数上限、形态键/修改器限制均保留。失败不替换用户模型。

## 数据与下游影响

这是现有云端 Blender 几何预处理，不引入浏览器 Python、本地 agent 或新拓扑引擎。GPU/CPU/Worker/shader、UV 绘制/烘焙/导出继续读取同一最终验证 GLB，不新增旁路或降低分辨率/QA。UV 的逐角数据和材质沿用 Blender GLB 管线；不承诺减面本身无纹理损失。

Project Schema、Command/CAS、ownership、verified assets 和请求资源限制不改。原文件和历史工程不变，无数据迁移。回滚恢复 v1.0.2 的减面脚本及确认/进度文案，只影响后续导入，不自动重写已导入资产。
