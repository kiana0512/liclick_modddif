# NORMAL-GUIDE-BACKGROUND/1.0.0

日期：2026-09-18。主模块 M12 捕获；UI-05 仅接线与会话状态。

## 用户要求与范围

法线参考图新增开关：开启黑底，关闭蓝底，默认关闭。单/多视图 ModelView 及两种局部重绘入口共用当前编辑器会话选择；刷新默认关闭。GPT 单/多视图未使用此法线输入，不显示此项。

## 实现与边界

- 5 个生产源码文件、局部改动。算法在 captureNormal，不放入 React/store。
- 法线 pass 背景使用黑色 RGB(0,0,0) 或蓝色 RGB(128,128,255)，Alpha=1，临时忽略 scene.background。raw geometry guide 使用线性数值，普通 sRGB target 使用对应颜色空间，最终 PNG 背景一致。
- 不按蓝色像素抠图；模型表面朝向相机时本身就是蓝色，必须保留。没有新增绘制 pass、整图 CPU 处理、Worker 重编码、网络字段或上传。
- 有明确 background 参数的远端捕获才生效；参数缺省保留既有 UI 法线缩略图和其他消费者。开关显式关闭是蓝底，不是透明底。
- 配置锁与提交锁都禁用按钮并在点击处理再次校验。捕获回调依赖底色，单/多视图每次生成重新捕获，禁止拿旧预览代替。异步任务使用发起时的闭包快照；局部重绘 fingerprint 与 metadata 记录底色。
- 冻结相机、输出尺寸、模型法线 shader、原蒙版/外扩、材质参考、QA、逐视角回贴和服务器原字节转发不变。GPU/CPU/Worker 投影、UV、导出只消费既有几何覆盖内法线；作者蒙版与深度不改。
- 不修改 Project/Layer/Capture/Generation 持久契约，仅复用可选 metadata 记录诊断。Command/CAS/ownership/verified assets 不变。

## 验证

- 实际 WebGL/PNG 测试：普通法线与 raw geometry guide，各 128²/2048²，黑→蓝→黑。背景 RGBA 分别精确为 (0,0,0,255)/(128,128,255,255)。各路径分别核对 625/167281 个内部像素，法线差异 0；重复黑底整图字节差异 0。验证捕获后 clearColor/clearAlpha/scene.background/原材质还原。
- 开关真实 JSX：默认关闭，开/关翻转，两种锁组合及手动调用禁用回调均保持锁定。
- 捕获包装：蓝/黑参数、冻结相机、2K 尺寸、取消；法线材质复用、绘制异常恢复、两个 renderer 隔离。
- 单/多视图 ModelView 与 GPT 局部重绘现有专项回归；TypeScript、生产构建及包体门禁。
- 无付费远端生成测试，未推送或部署。

无历史资产迁移，既有任务和 PNG 不重算。回滚此开关及参数接线即可恢复原背景；无需服务端、数据库或远端契约回滚。
