# 采集回读分段与法线预览独立离屏

- 主模块 M03，协作 M06/M08；UV-READBACK-SCHEDULING/1.1.1、CAPTURE-NORMAL-ISOLATION/1.0.0。
- 问题：颜色/蒙版/法线等采集仍一次回读整张图，异步 API 结束时的驱动拷贝会同步占用主线程。初始多视角法线预览还共用可见渲染器和场景临时材质，需排除正常视口被采集状态干扰。
- 实现：复用 1 MiB 分段回读，增加矩形高度支持，唯一最终缓冲、完整像素和行序保持。所有在途回读排空后才释放目标；可见渲染器保留绘制边界，独立上下文最多八条并发。
- 离屏：法线缩略图及正式几何法线引导在独立 WebGLRenderer 和场景副本执行；材质/可见性只改副本，骨骼也独立，原几何数组只读共享。相机拟合与轮廓检查也使用副本；渲染任务串行、交互结束后开始，空闲 20 秒释放额外上下文及其 GPU 资源。存在额外一份几何 GPU 上传和上下文开销，未声称零显存成本。创建失败明确报错，不悄悄回退修改可见场景。
- 验证：方形与 2048×1537、1537×2048、4096×512 矩形完整字节及尾条带对照；真实采集函数的绘制边界、材质/背景/FBO 状态恢复和失败清理通过。实际 Three 场景/骨骼克隆验证原模型材质、可见性不变；串行所有权、失败后可再执行及空闲释放通过。驱动替身用于确定性回归，不冒充用户页面 FPS 或实际离屏像素对照。
- 审计：原捕获尺寸、色彩输出、相机/mask/depth、引导图及 PNG Worker 保持；GPU/CPU/Worker/shader 数学、正式 UV/回贴、QA、Command/CAS/ownership、持久化和导出协议不改，无 Schema/资产迁移。回滚离屏包装和矩形回读调用即可，原成功资产保留。
