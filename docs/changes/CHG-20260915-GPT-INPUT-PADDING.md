# 模型轮廓裁切时完成通用比例适配

- 主模块 M03 捕获 / M04 生成；协作 M08 重绘、M12 任务协议、M15 发布。
- 算法 `GPT-CONTENT-FRAMING/2.0.0`；状态：候选验证，实际发布以最终提交和部署记录为准。
- 范围：GPT 单/多视图贴图、GPT 局部重绘。六视图参考两阶段生成、原 ModelView 不变。

## 输入阶段

1. 从完整模型 coverage/几何法线 alpha 提取轮廓，保留最长边 3%（至少 2px）边距。不以作者局部蒙版、材质颜色、地面网格决定外接框。
2. 将带边距比例换算为最长比例项 100、另一项四舍五入的整数对，再约分；最大 3:1。不是固定 69:100，也不是限定七个预设，更不是把 1507×597 写成 1507:597。后一例换算为 100:40，提交 5:2。
3. 以分辨率档位边长 E=1024/2048/4096、比例 r，预测输出 W=round(E×sqrt(r)/16)×16、H=round(E/sqrt(r)/16)×16。此公式是根据六个历史任务及 UI 69:100→848×1232 推导验证，并非声明远端严格保证。请求仍保留原用户质量/分辨率映射。
4. 裁切画布扩到上述输出的精确比例，整数平移原像素，不伸缩、不裁掉模型。只复制原裁切区，新增边透明；结合图和法线使用同一范围，可选材质参考不动。完整画布内存安全预检在上传/付费之前执行。
5. 服务端复验比例、预期尺寸及档位，只发送 aspect_ratio_w/h，移除 preset aspect_ratio。技能注册表确认自定义整数对优先，不能把旧字段共存直接归因于远端比例改变。像素精确上传、取消、保存门禁继续生效。

## 回图及恢复

- v2 必须符合本次预期输出尺寸，检查 alpha>=128 的轮廓外接框，允许 max(16px, 模型最长边2%) 误差；空白、明显移动/缩放或不符尺寸的结果保留但不回贴，不自动再次付费。该粗检不识别内部变形，不承诺生成必然对齐。
- 输出按原生尺寸整数平移到透明原坐标画布，不拉伸、不缩小远端细节；完整画布 ceil 及整数坐标至多产生像素级取整。后续原投影相机/depth/作者蒙版仍控制写入。
- v1 兼容独立16px网格取整：横/纵尺寸对应的同一缩放区间必须相交，而非使用面积平均缩放分别比较8px。六个真实成功回图通过；明显异比例仍拒绝。
- framing v2 增加 cropBounds/subject、ratioWidth/Height、outputWidth/Height。cropBounds 避免通用持久化过滤器将 content 字段省略；实际保存与加载函数回归覆盖完整往返。无 framing 或 v1 旧任务保持兼容，不迁移历史，不删除结果。
- 回滚：前后端成套部署；若已有 v2 任务，不能直接回滚到仅支持 v1 的读取器。应保留 v2 协议/还原读取器，仅关闭新 v2 生产；已还原资源继续保留。无 SQL Schema 或资产迁移。
