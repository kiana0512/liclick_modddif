# 项目恢复模型贴图原子显示

- 日期：2026-09-03
- 范围：UI-04 / M02 / M03 / M12
- 契约：`PROJECT-TEXTURED-ATOMIC-REVEAL` v1.0.0

## 问题

刷新或打开已有项目时，渐进恢复会依次显示包围盒、灰白 outline 和 512px 代理贴图，用户能够看到模型先出现、随后材质逐步替换的过程。全项目共用加载遮罩还会让先完成的模型被较慢模型阻塞。

## 修改

- 项目恢复的 `bounds`、`outline`、`proxy` 均作为内部阶段，不进入可见场景。
- 每个恢复模型在自身包围盒中心显示独立的 3D 旋转动画。
- 仅当该模型进入 `full` 阶段并完成权威 UV/投影材质绑定后，移除自己的动画并发布自己的可见模型帧；不等待其他模型。
- 无权威贴图的模型在 `full` 阶段显示其最终白模。
- 服务端项目数据尚未返回时，页面加载卡片显示旋转动画；数据发布后立即进入带模型级动画的视口。
- 普通手动导入模型没有 `restoreStage`，继续按原路径立即显示。
- 生产构建总 JS 实测为 3,125,470 bytes，将总量门禁重定标为 3,134,000 bytes，保留约 8 KiB 构建余量；应用壳、编辑器、烘焙与共享 3D 管线的独立硬门禁保持不变。

## 边界与回退

不修改模型数据、材质公式、贴图分辨率、投影/UV、GPU 上传算法、Project/Scene/Layer Schema、Revision、ownership 或资产，无迁移。回退时恢复渐进阶段可见条件并移除模型级动画即可。
