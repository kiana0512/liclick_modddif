# CI 包体余量修复

主模块 M15，协作 M14；WORKSPACE-API-DEDUP/1.0.0、RELEASE-PREPUSH/1.1.0。

## 原因与改动

GitLab build #3581736 / #3581952 的前置校验全部通过，但总 JS 分别为 3,256,504 / 3,256,508 字节，超过原上限 4 / 8 字节。本地分支与时间元数据不同，原检查没有留余量。

只合并 workspaceApiClient 中重复的上传 URL 编码、XHR 上传进度回调和 FileReader 转码。fetch/XHR/直传分支、credentials、超时、错误文本、重试、三并发队列、关键保存及付费提交顺序不变。原 Blob 实例和字节不改，未知上传总量仍回退 Blob.size。

推送前使用带 +00:00 偏移的时间元数据，执行原 CI 命令后额外检查 256 字节总包余量；原 CI 的各块上限与总上限均未放宽。分支元数据仍随分支变化，余量不等于跨平台产物必然完全一致，必须单独确认实际 CI 状态。

## 验证

- 真实辅助函数测试覆盖 URL 特殊字符、可知/未知/零上传总量、完成进度、无监听者、FileReader Blob 所有权与错误身份；原混合上传队列测试保留。
- 包体门禁测试覆盖超出 8/4 字节、恰好上限、余量 255/256/430 字节及非法参数。
- Cloud + performance-lab、master 元数据及带 UTC 偏移时间的本地构建：3,256,070 字节，余量 430 字节；比该提交失败 CI 产物少 438 字节。完整发布验证以最终执行记录为准，不代表远端 CI 已通过。

## 迁移和回滚

无数据库、Schema、资产或历史任务迁移；GPU/CPU/Worker/shader、投影/UV/export、分辨率、QA、Command 幂等、Revision CAS、ownership 全部不变。不重启数据库、不提交生图。回滚本次代码和脚本即可，但会恢复包体贴上限风险；不得回滚此前云端保存修复或删除资产。
