## 契约

返图只作为冻结取色来源。先按原始作者范围、模型轮廓内缩及捕获可见性准备 UV 颜色；笔画在当前视口逐像素验证最前面的三角形 ID，再写对应 UV。大笔刷可同时写护栏和孔洞里可见的后板，不锁定起笔部件；被遮挡、背面、来源没有有效像素的位置不写。不同三角形投影到相同返图像素不再共享作者覆盖。

GPU 负责 UV 光栅化和当前视口可见性；CPU 只处理有界脏区、历史及资产编码。最终 UV 分辨率使用用户设置，不启用旧的逐笔整图重烘分支，不降采样最终纹理。颜色为 sRGB BaseColor，直通 Alpha；烘焙不含灯光/曝光，预览只施加一次显示变换。屏幕坐标左上原点，标准 UV 左下原点，PNG 左上原点。画笔最大覆盖合并，擦除只改覆盖，不补回工作选区。

UV 缺失/退化/越界/重叠必须报告；不得自动重排 UV 或修改原模型。检查针对当前分辨率的可寻址 texel，不保证识别亚像素重叠。尺寸超过设备能力直接失败，不降质量；极限显存耗尽/上下文丢失仍需设备压力验收。

新结果为独立 UV RGBA 层；不合并、不删除用户已有图层。旧投影重绘层维持原编辑与保存逻辑，不批量转换。新 UV 图层重开、合并、颜色导出和 FBX 消费同一份 RGBA，不再重放投影或二次乘 Alpha。保留生成来源作为元数据，不把来源图当 UV 颜色。

每笔占一个历史位置；异步像素读回完成前撤销等待现有 paint boundary，清除工作选区与笔画共同撤销。晚到操作校验工程 epoch 和目标身份；保存仍经 verified assets / Command 幂等性 / Revision CAS，不修改 ownership。实时 GPU 资源不作为持久化资产，保存必须等待对应完整像素版本。

## 验证与回退

必测：同一来源像素对应两个分离 UV 面、前后遮挡、护栏孔洞与大笔刷、旋转视角、连续笔画/擦除、撤销重做、源 Alpha/轮廓裁切、UV 重叠、全尺寸、源/工程切换及释放；真实 WebGL 夹具加现有全套回归、typecheck/lint/build。

不宣称已上线或通过用户模型帧预算。代码回退新入口可恢复旧生成行为；已写入的 UV 图层仍按普通 UV 资产读取，不回退或重写用户数据。

## 实现与实测

- 独立模块：`uvRepaint` 管理 UV 光栅化、当前相机 face ID/depth 可见性、256px 脏瓦片；`uvRepaintSession` 延迟加载、提交/历史；`uvRepaintLayer` 发布独立图层；`uvRepaintState` 为轻量共享契约。
- 相邻三角形像素边界使用导数计算像素中心的平面深度，避免单一 face ID 误拒绝形成对角漏画；不扩大整体遮挡容差。
- GPU source/output 分开，来源准备后冻结；源切换释放 source/ID/几何，output 留给已有图层显示，视口卸载后解除绑定并释放。读回失败阻止不完整快照进入保存/导出。RGBA8 单张 4K 为 64 MiB，source+output 为 128 MiB，另需 CPU 镜像、ID/depth、几何和历史；不是零额外内存。
- 原生 UV 层跳过旧重绘导出的轮廓扩展与 rendered-color 亮度补偿。手动 UV 合并先把 live RGBA 冻结为临时 Blob，CPU/Worker 都读取该快照，finally 释放 URL，不替换用户源层。
- `pnpm run test:regression`：110 项契约通过。`pnpm run lint`：0 error、14 个既有 warning。Cloud `tsc -b && vite build` 通过。
- `node scripts/run-uv-repaint-browser.mjs --viewport --perf`（独立 headless Edge）：可见/遮挡/分离 UV 面、大笔刷、护栏孔洞、转相机、擦除/撤销/重做、UV 重叠拒绝、sRGB 与真实投影源 shader 通过；实际 React ViewportCanvas 绘制后 5,914 个覆盖像素，擦除/撤销/重开正常，PNG 1024²，FBX 临时纹理中心 `[211,68,34,255]` 与原生像素一致。
- CPU Canvas 的透明像素 RGB 在 PNG 往返时可能被归零/量化；验证覆盖 alpha 不变、预乘可见颜色误差不超过 1 通道值，不宣称透明隐藏 RGB 字节完全一致。
- 320,000 三角形的合成平面、4K：最近一次 constructor 59ms，准备 278.9ms，12 次笔刷 CPU 提交中位数 0.8ms、最大 3.6ms、48 个脏瓦片。这只衡量合成夹具和 CPU 命令提交，不代表用户模型 FPS/全链路时延。
- 新能力按需加载后，同配置 Cloud 总 JS 从 3,163,590 增至 3,185,232 字节，新增 21,642 字节；明确分配 22,000 字节功能预算，high-bake 共享入口预算增加 2,000 字节至 702,000。其余 chunk 门禁、质量、最终分辨率和回归不变，未关闭预算检查。最终预算检查通过（86 chunks）。
- 追加浏览器验证：UV 缺失/越界/退化都拒绝；真实生产源 shader 的全透明输入及冻结作者蒙版禁区均不产生 UV 笔画像素。
