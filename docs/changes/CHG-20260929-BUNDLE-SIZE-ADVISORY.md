# 包体阈值改为非阻断报告

- 日期：2026-09-29；状态：待正式门禁和远端 CI 验证。
- UI/use case：M15 发布检查；`RELEASE-PREPUSH/1.3.0`，Patch，无运行时算法、数据或 Schema 变更。
- 项目负责人明确要求总 JavaScript 包体报告阈值至少 10 MiB，且功能运行正常时不能因字节数阻断 CI。总量现设为 10,485,760 bytes；现有首页、编辑器、烘焙、共享管线和懒加载 route 的阈值作为单项观察指标保留。
- `check-web-bundle-budget.mjs` 继续统计正式构建的所有 JS 原始字节并报告每项余量；总量、单项、256 字节发布元数据余量及预期 chunk 名称偏离均输出告警而不返回失败码。构建产物目录缺失、脚本参数无效仍失败。
- `.gitlab-ci.yml` 的 verify、typecheck、lint、Web/Server 回归、Cloud 边界、正式构建、云产物完整性、部署模拟、容器构建与 rollout 健康检查维持原阻断行为；只调整字节预算，不靠降低质量或分辨率达标。
- 验证：Cloud 部署脚本测试覆盖低于/高于 10 MiB、256 字节余量与非阻断退出码；最终提交需执行 `verify:prepush`，远端 pipeline 和生产 release 独立核对。自动测试不能代替已登录用户的实际付费生图验收。
- 迁移/回滚：无持久化迁移。回滚报告脚本和阈值可恢复旧 3,271,000 字节硬门禁，但可能再次因数百字节差异阻断正常功能发布。
