# ADR-0002：浏览器本地计算策略

- 状态：Accepted
- 日期：2026-08-21

## 决策

普通贴图计算只允许选择浏览器本地后端。能力不足时降低质量、并发度或切换本地兼容后端，不允许自动提交到 LI3D 服务器补算。

“普通贴图计算”指视口、绘制、投影、图层合成、蒙版、图片编码和交互式修补内核；不包含 ADR-0011 规定的 Auto UV、自动拓扑、生产 PBR Bake 或显式 AI 任务。

后端优先级：

1. WebGPU Worker；
2. WebGPU 主线程协作式调度；
3. WebGL2 主线程；
4. CPU Worker（优先 WASM）；
5. CPU 主线程限质降级。

本地缓存优先使用 OPFS，其次 IndexedDB，最后仅保留内存会话。缓存不成为项目权威数据，项目 Revision 和资产哈希仍由云端控制面管理。

## 强制约束

- `serverFallbackAllowed` 在协议类型和运行计划中固定为 `false`。
- 浏览器启动时发布实际能力与选定后端，供性能诊断和 E2E 使用。
- WebGPU、Worker 或 OPFS 缺失只能产生显式降级，不得改变计算执行平面。
- AI 推理是独立的显式云端任务，不得伪装为普通 Bake、合成或蒙版操作。

## 当前迁移关系

现有 Worker/WebGPU 合成、拓扑栅格化、PNG 编码和质量融合实现继续复用。后续 Engine Session 将统一持有设备、队列、内存预算和取消令牌，逐步替代组件内散落的后端选择逻辑。
