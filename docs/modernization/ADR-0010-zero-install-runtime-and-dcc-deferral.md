# ADR-0010：零安装浏览器运行时与 PS/DCC 暂缓

- 状态：Accepted
- 日期：2026-08-21

## 决策

现代化分支不再保留、构建或分发 Windows 本地组件。以下内容必须消失：

- 本地组件安装包、下载路由、安装按钮和版本门禁；
- `127.0.0.1:4618`、localhost 守护进程、身份凭据桥接和开发代理；
- 本地组件启动、停止、打包脚本及发布模式；
- 以本地组件缺失为理由阻断贴图工作区的逻辑。

原组件承载的核心能力按职责迁移：

- 视口、贴图绘制、投影、图层合成和蒙版交互：浏览器 WebGPU/WebGL/WASM/Worker，使用用户 CPU/GPU；
- 项目、资产、身份、任务恢复、生图、局部重绘：同源云端控制面或受控生产服务；
- Auto UV、自动拓扑和生产 PBR Bake：上传输入到 LI3D 应用服务器，由独立 GPU/AIGC API 集群返回正式产物；绝不以浏览器 xatlas、三角简化或 BVH Bake 替代。

## PS/DCC 标签

Photoshop、3ds Max、Blender 的实时启动和双向桥接标记为 `DEFERRED_PS_DCC_BRIDGE`，不属于本轮上线范围，也不在浏览器界面暴露入口。

“PS/DCC 暂缓”不等于删除生产工具箱。Cloud 首页必须保留工具箱入口和完整能力清单；能在浏览器执行的工具迁移到 WASM、Worker 或 GPU，批处理迁移为云端任务。只有依赖宿主进程启动、工程注入或双向桥接的部分使用 `DEFERRED_PS_DCC_BRIDGE` 标签。

原因是标准浏览器安全模型不能在零安装条件下任意启动或控制本机 DCC。若未来恢复，必须单独立项并重新选择方案；不得重新把本地守护进程变成核心依赖。现阶段支持的替代边界是用户主动的标准文件导入、导出与下载。

## 验收门槛

- 默认开发构建和发布构建使用同一 Browser/Cloud 运行时；
- 安装器旧 URL 返回 404；
- Web 产物没有可执行文件、组件字符串或 loopback 桥接；
- 浏览器本地计算证据必须来自实际 Worker/WebGPU/WASM 任务，不能用 UI 文案代替；
- PS/DCC 暂缓功能不得出现可点击但必然失败的入口。
