# Li3D 优化总结（2026-08-18）

## 1. 总览

今天的优化重点围绕局部重绘三图输入一致性、生成状态稳定性、图层叠加顺序、视口显示隔离，以及重绘画笔交互展开。

本次整理只记录当前已经保留并生效的修改，不包含已经回退的尝试。

## 2. 局部重绘输入与视角锁定

### 2.1 点击生成时锁定摄像机

- 点击“局部生图”时立即保存当前摄像机快照。
- 当前视角白模、当前视角带材质预览图和本地蒙版统一使用该摄像机快照捕获。
- 提交任务后再旋转或切换视角，不会改变已经提交给 ComfyUI 的构图与参考视角。
- 避免任务启动前几秒因用户继续操作视口而导致三张输入图视角不一致。

### 2.2 当前视角参考图统一为平面 Base Color

- 当前视角带材质预览图固定使用 `2048 × 2048` 正方形输出。
- 捕获时使用平面 Base Color 效果，不再把 PBR 灯光、曝光或扫光结果烘进参考图。
- 白模主图、平面材质预览图与本地蒙版保持同一相机、同一画幅和同一比例。
- ComfyUI 返回结果继续按平面颜色回贴，PBR 视口仅在最终显示阶段叠加一次光照，避免重复光照和颜色偏差。
- 蒙版仍只用于本地限制回贴区域，不传入 ComfyUI 工作流。

## 3. 局部生图状态稳定性

### 3.1 修复偶发持续转圈

- 服务返回生成图片后，立即同步结果、释放前台提交状态并展示预览。
- 结果文件本地化、蒙版保存和项目持久化调整为后台执行，不再阻塞生成按钮结束状态。
- 后台保存失败时沿用项目保存恢复逻辑，不会重新激活已经结束的生成转圈状态。
- 修复首次触发局部生图时，图片已经返回但界面仍持续等待的偶发问题。

## 4. 图层顺序与 PBR 显示

### 4.1 合并 UV 图层作为明确层级边界

- 可见的“合并 UV 图层”现在作为投影图层显示顺序的明确边界。
- 位于合并 UV 图层上方的局部重绘图层继续正常显示。
- 位于合并 UV 图层下方的投影图层由合并 UV 结果覆盖，显示效果与右侧图层列表顺序一致。
- 图层显隐、驻留材质更新和视口模式切换统一遵守该层级规则。
- 修复上方局部重绘图层被下方合并 UV 图层遮挡的问题。

### 4.2 局部重绘参与统一 PBR 光照

- 局部重绘结果按 Base Color 图层处理，不再作为已经带光照的非受光材质显示。
- 在 PBR 模式下，局部重绘区域与模型其他区域接受同一套环境光和扫光参数。
- 保持平面模式下的绘制颜色与提交给 ComfyUI 的当前视角预览一致。

## 5. 视口辅助对象隔离

### 5.1 修复偶发灰色地面格子

- 局部重绘使用的屏幕预览辅助平面移动到编辑器专用相机层。
- 辅助平面不再参与场景射线检测和接触阴影计算。
- 选中蒙版、切换工具或进行其他编辑操作时，不再把全屏预览辅助对象误显示为模型下方的灰色平面。

## 6. 应用重绘画笔交互

### 6.1 左键绘制、右键擦除

- 局部重绘结果应用画笔增加擦除能力：左键将生成结果画到模型，右键擦除已应用的局部重绘内容。
- 绘制与擦除均使用当前画笔大小和不透明度参数。
- 右键拖动应用画笔时阻止浏览器右键菜单和视口相机操作，避免交互冲突。
- 工具面板文案同步更新为“左键绘制，右键擦除”。

## 7. 回归验证

以下检查均已通过：

- 投影图层与局部重绘回归测试：`test:projection-layers`。
- Web TypeScript 类型检查：`typecheck`。
- Web 生产构建：`build`。
- Git 差异格式检查：`git diff --check`。

新增或扩展的自动检查覆盖：

- 三张局部重绘输入共用冻结摄像机快照。
- 当前视角预览使用平面 Base Color 捕获。
- 生成结果返回后前台等待状态及时结束。
- 合并 UV 图层与上下投影图层的顺序关系。
- 局部重绘结果在 PBR 模式下接受统一光照。
- 屏幕预览辅助平面不参与世界场景显示与阴影。
- 应用重绘画笔左键绘制、右键擦除。
