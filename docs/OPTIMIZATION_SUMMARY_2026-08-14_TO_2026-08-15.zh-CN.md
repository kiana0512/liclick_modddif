# Li3D 星期五至今优化总结

> 时间范围：2026-08-14（星期五）至 2026-08-15
>
> 范围：仅记录当前保留并生效的优化，以及同期合入后继续保留的远端能力。

## 1. 总体结果

本阶段围绕贴图生成、局部重绘、图层显示、内容识别修补、合并 UV 和视口性能进行了集中优化。最终形成了以下几条稳定链路：

1. 局部重绘采用“双图生成、蒙版本地回贴”的工作流，生成与绘制步骤更清晰。
2. 蒙版绘制增加可见面保护，降低背面穿透、斜角条纹和错误覆盖。
3. 图层缩略图、可见性恢复和 GPU 纹理发布更加稳定。
4. 纹理生成过程减少中间弹窗，只保留必要的最终结果反馈。
5. 内容识别修补与 UV 图层合成的边界更准确，避免把 UV 岛外区域误认为缺失内容。
6. PBR 扫光仅作用于最终合并 UV 图层，并支持实时调整方向和强度。
7. 合入局部重绘 GPU 累积、滚轮事件合并和视口交互优先等性能能力。

## 2. 局部重绘工作流与交互

### 2.1 双图材质编辑工作流

- 局部重绘生成输入统一为当前视角白模和多视图材质参考图。
- 蒙版不提交到 ComfyUI，只在生成结果返回后控制本地绘制和回贴区域。
- 当前阶段使用固定材质迁移提示词，用户无需输入局部重绘提示词。
- 输出仍为单张结果图，保持现有前后端接口和结果处理方式。

### 2.2 三步工具状态更清晰

- 蒙版画笔和局部生图按钮不再显示容易被理解为“已经完成”的绿色对号。
- 局部生图按钮保持可用，没有绘制蒙版时也可以直接生成。
- 选择蒙版工具后，局部生图按钮通过呼吸效果提示下一步操作。
- 生成任务开始后持续显示生成中状态，结果返回后再引导用户选择局部重绘画笔。
- 已返回的局部重绘结果持续可用，误切换工具后仍可重新进入局部重绘画笔。
- 进入局部重绘画笔时会清理临时蒙版记录，避免旧选择区域干扰新一轮操作。

### 2.3 画笔参数拆分

- 绘制蒙版和应用局部重绘使用独立的画笔参数状态。
- 蒙版工具只保留画笔大小，蒙版不透明度固定为 100%。
- 局部重绘画笔保留画笔大小和不透明度调节。
- 参数面板会根据当前工具显示对应标题和可用选项，避免调节参数时误切换工具状态。

## 3. 蒙版正确性与绘制性能

### 3.1 可见面与深度保护

- 蒙版投影使用当前视角深度作为可见面判断依据，只接受视点前方命中的表面。
- 深度数据未准备完成时不归档投影，避免把无深度约束的结果永久写入 UV 蒙版。
- 捕获深度边缘增加邻域匹配，减少薄结构和轮廓处因单个空深度像素产生的断裂。
- 正反面覆盖分通道累计，预览时根据当前观察面读取对应结果，降低背面蒙版显示到正面的概率。
- 按命中的 Mesh 记录蒙版作用范围，未被画笔命中的网格不参与蒙版覆盖。

### 3.2 斜角边界与条纹控制

- 局部重绘覆盖采用明确的可见性阈值，达到条件时完整显示，未达到条件时不显示。
- 对具有可靠深度捕获的局部重绘，以深度判断作为主要边界，避免法线连续权重产生半透明条纹。
- 对缺少深度数据的兼容路径保留安全朝向判断，防止高风险角度错误上色。
- 预览合成和最终投影材质使用一致的硬边界逻辑，减少预览与最终结果不一致。

### 3.3 实时绘制性能

- 历史蒙版使用可复用的 GPU 累积缓冲，不再随笔画数量持续增加完整覆盖层。
- 停笔时不再同步扫描整张高分辨率蒙版，也不立即编码整张 PNG。
- 蒙版反选通过 GPU 状态完成，避免 CPU 读回和逐像素反色。
- 当前笔迹可使用深度裁剪的快速屏幕预览，减少绘制过程中整台模型重复更新。
- 只为本次真正命中的网格准备覆盖资源，降低复杂模型上的 Draw Call 和材质更新压力。
- 相机滚轮事件按显示帧合并，同一帧内累计缩放量后只更新一次相机，兼顾流畅度和缩放距离准确性。

## 4. 图层显示、恢复与缩略图

- 局部重绘图层缩略图支持读取实时纹理源，并正确组合持久化颜色图与局部蒙版。
- 图层大图预览与缩略图共用有效解码源，内容 revision 更新后会刷新显示。
- 内容识别修补图层在纹理完成解码并上传 GPU 后再原子发布，避免首帧白块或图层开启后不显示。
- 图层恢复会重新同步当前真实可见性，刷新页面前关闭的图层在重新开启后可以重新进入渲染链路。
- UV 预览签名加入图层角色，合并 UV、局部重绘和内容修补之间切换时能够触发正确的材质状态更新。
- 局部重绘临时层、持久层和普通投影层的显示职责进一步拆分，避免重复叠加或缩略图空白。

## 5. 内容识别修补与合并 UV

### 5.1 内容识别边界

- 参考图解码转移到 Worker 和 OffscreenCanvas，降低大图解码对主线程的阻塞。
- 视口空白覆盖提示与内容识别共用同一套覆盖阈值，减少“视口显示缺失但修补未识别”的差异。
- 修补范围限制在严格 UV 三角形覆盖区域，不把 UV 岛外围保守扩张区域写成可见颜色。
- 排除 UV 岛自然产生的一像素边缘，减少修补图层上的裂纹状轮廓。
- 修补图层作为稀疏底层参与 UV 合成，普通 UV 和新投影结果保持在其上方。
- 保留透明区域的隐藏 RGB 外扩，用于双线性采样，同时不把外扩区域作为可见修补内容发布。

### 5.2 合并与烘焙衔接

- 缺少合并 UV 时，仍在贴图编辑器中完成合并和保存，再进入烘焙流程。
- 合并时明确区分基础 UV、内容识别底层和投影图层的合成顺序。
- 合并结果完成编码、持久化和图层同步后再交给烘焙，降低页面切换造成的状态丢失。
- 已有 UV 的外部模型可以直接保存为当前 UV 阶段结果并继续传入烘焙。

## 6. PBR 扫光与材质预览

- PBR 扫光只作用于最终的“合并 UV 图层”。
- 普通投影、局部重绘、内容识别修补和其他编辑图层保持原始显示颜色，不参与 PBR 扫光。
- 修复合并 UV 专用材质未进入实时光照同步的问题，调整参数后直接更新驻留 GPU 材质。
- 修复扫光方向数组与 `THREE.Vector3` 类型不一致的问题，扫光角度能够正确转换为归一化方向。
- 曝光、环境光、主光和扫光方向可实时调整；主光为 0% 时不会产生方向性扫光。
- 统一默认参数：曝光 `1.00x`、环境光 `42%`、主光 `100%`、扫光方向 `38°`。
- 初始化和“恢复默认”共用同一份默认配置，避免两处参数长期漂移。

## 7. 生成界面与反馈降噪

- 纹理提示词输入框采用两行起始高度，并随内容增长自动向下扩展。
- 增加 1K、2K 生成规格选择，并映射到对应输出分辨率。
- 局部重绘生成面板与普通纹理生成面板保持统一的多视图、单视图和重绘结果结构。
- 参考图预处理、任务重连、结果恢复、自动投影等待和后台修补等过程信息转入后台日志。
- 点击生成纹理后，只保留最终“纹理贴图已生成”成功提示；进度仍由生成面板自身展示。
- 进入项目时的模型和任务恢复在后台执行，不再连续弹出恢复类提示窗口。
- 自动内容识别修补支持静默前台模式，生成流水线可以继续完成后处理而不额外叠加弹窗。

## 8. 工作流与界面精简

- 顶部主流程保留“贴图、UV、烘焙”，自动拓扑入口暂不展示。
- 移除流程按钮之间的箭头，降低导航噪声。
- 旧拓扑入口统一引导到 UV 阶段，已有历史项目仍能继续进入后续流程。
- 模型选择中的两个候选明确标识为高模和低模，降低误选高模 UV 拓扑的概率。
- 多视图模板保留正面、左前 45°、顶部、左侧、右侧和底部六个方向。

## 9. 合入并保留的远端优化

星期五同步远端 `master` 后，保留并整合了以下能力：

- GPU 蒙版累计、直接材质混合和兼容 Overlay 路径。
- 蒙版实时显示、擦除、反选与状态保持优化。
- 画笔输入缓存、可绘制表面缓存和资源释放完善。
- 相机滚轮事件合并和视口交互状态通知。
- 投影纹理数组 Worker 处理、分条上传及交互期间的上传窗口控制。
- 图层面板与实时纹理源联动，减少无效缩略图和预览更新。
- 性能观测脚本补充了投影图层可见性、合并 UV 光照参数和纹理发布回归检查。

本地产品交互与远端性能能力合并后，局部重绘仍保持当前双图输入、蒙版本地回贴、可见面保护和独立画笔参数逻辑。

## 12. 结论

本阶段已经把局部重绘从生成、蒙版、结果应用到图层持久化串成更清晰的完整流程，并将蒙版可见面约束、硬边界覆盖、实时预览和 GPU 累积结合起来。生成端减少了过程性提示干扰，内容识别与合并 UV 的边界更加明确；最终合并 UV 图层具备独立、可实时调节的 PBR 扫光能力，同时保持其他编辑图层的原始颜色显示。
