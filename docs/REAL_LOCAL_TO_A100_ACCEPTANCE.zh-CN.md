# LI3D 真实本地验收与 A100 发布边界

## 唯一用户形态

LI3D 对最终用户只提供网页，不安装或依赖本地组件、桌面伴随程序、MinIO、Docker 或浏览器扩展。

- 真实本地验收入口：`http://127.0.0.1:4517/`
- A100 正式入口：`http://10.3.2.59:44770/li3d/`

## 一键启动真实本地环境

首次使用前，在飞书开放平台同一自建应用的“安全设置 → 重定向 URL”保留生产回调，并新增：

```text
http://127.0.0.1:4517/api/auth/feishu/callback
```

本地密钥只保存在被 Git 忽略且限制 ACL 的 `secrets/li3d-dev.env`。启动命令：

```powershell
corepack pnpm preview:real-local
```

快速复用已经构建的前后端：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run-real-local-preview.ps1 -SkipBuild
```

该命令只启动一个 `4517` 后端进程，同时提供网页、API、真实飞书 OAuth 和本地工作区文件。模型上传在云对象存储未配置时自动流入该后端的受认证项目目录，不允许要求开发者再启动本地组件。

## 本地与 A100 的相同点和隔离边界

| 项目 | 真实本地验收 | A100 正式环境 |
| --- | --- | --- |
| 用户入口 | 单一网页 | 单一网页 |
| 前后端契约 | 同一仓库、同一 API 和项目结构 | 同一仓库、同一 API 和项目结构 |
| 身份 | 真实飞书 OAuth | 真实飞书/IDaaS 配置 |
| 资产入口 | 后端受认证上传接口 | 后端签发对象存储直传 |
| 资产持久化 | `workspace/users/.../projects/.../assets` | A100 自己的对象存储配置 |
| 项目数据 | 本机 `workspace` | A100 自己的数据目录/数据库 |
| 外部本地组件 | 禁止 | 禁止 |

两边不共享项目数据和模型文件。本地验收只验证同一产品代码和 API；发布时只提交代码，不能把本地工作区、密钥或存储配置推到 A100。

## 多模型稳定加载策略

1. 先恢复全部模型几何和上一次可见画面，禁止黑帧、白膜消失或对象突然隐藏。
2. 全场景优先加载最大 512px 的材质代理；代理就绪前保留已有材质/轮廓。
3. 当前选中模型优先升级精确材质；用户切换模型或贴图工作区时复用几何与代理缓存。
4. 非选中模型仅在空闲时逐个升级全质量，升级完成前继续显示代理。
5. 后台恢复不得覆盖用户当前选择。
6. 首页缩略图从完整场景的代理或全质量状态生成，不因仍有后台升级任务而复用旧缩略图。

## 发布前强制验收

- 真实飞书登录，页面不得出现 `Liclick Dev User` 或 `dev-mock`。
- 新建项目可导入模型，关闭并重开后模型与材质仍存在。
- 九模型场景加载期间无黑闪、消失或选中状态跳动。
- 选择模型后进入贴图工作区能立即显示代理材质并升级精确材质。
- 首页缩略图反映完整多模型场景，不显示历史白模头像。
- 自动拓扑 V6 入口保持隐藏。
- Web typecheck、回归测试、生产构建和 CI/CD 全部通过后才可合并 `main`。
- A100 发布后核对 `/li3d/api/ready`、`/li3d/api/health`、`/li3d/api/release` 与真实浏览器页面。
